## 维护约定

1. 新文档放对应分类目录；没有合适分类时先放到 `00_总览/` 并在本文件登记。
2. 结论必须带时间、范围与证据；**验证之前不得写通过**。
3. 过期内容移入 `99_归档/`，标注取代它的文档，不直接删除。归档**只增不改**，其内部链接不随整理维护。
4. 本文件是唯一入口，路径变更后请同步更新这里和相关文档内的链接。

### 文件命名与内容版本

- 新文档：文件名用**用途名**，版本号只写在正文。
- 模块 PRD 与部分配套材料保留 `_vX.Y.Z` 后缀作**稳定外链标识**；其**内容版本以正文首行为准**，与文件名可能不一致（例如 `测试与部署计划.md` 正文为 v0.2.1）。
- 归档快照保留原文件名与原路径，不改写。

### 内容版本规则（语义化版本）

沿用 `v主版本.次版本.修订版本`（源自 2026-09-09 文档包，原文见 [归档 README](./99_归档/历史版本/README_20260909模块拆分前.md)）：

| 升级位 | 触发条件 |
|---|---|
| 主版本 | 产品边界或教学责任发生重大变化 |
| 次版本 | 新增或删除教学场景、典型任务和关键流程 |
| 修订版本 | 不改变产品决策的文字、链接和细节修正 |

新版本**不覆盖旧文件**，由本索引或对应目录指向当前版本。
