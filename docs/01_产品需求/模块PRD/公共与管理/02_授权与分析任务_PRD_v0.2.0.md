# 公共与管理｜授权与分析任务 PRD v0.2.0

## 1. 产品定义

- **这是什么功能：** 管理教学对象访问、AI任务状态和异常处理。
- **帮助用户解决什么问题：** 避免新增出题与练习AI绕过答案开放或资料权限。
- **为平台带来什么价值：** 为服务接入提供可追溯管理规则。

> **实施前置依赖：** 服务限额、任务恢复、日志及资源配置D-F03至D-F05。 统一见[实施依赖清单](../../../03_实施与进度/实施依赖与待确认清单.md)。已确认产品行为不等于服务已接通或医学效果已验证。

## 2. 产品结构

授权范围 → 任务列表 → 失败处理 → 用量与记录。

共用阶段、数据版本与权限原则见[需求总纲](../../需求总纲.md)，模块入口见[目录](../README.md)。

## 3. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| C-OPS-01 | 配置授权 | 病例、题库、练习开放与考试分配 | 资源阅读、资源编辑、题目确认、开放练习、发卷、阅卷、录音及画像分别控制。标准库维护与他人画像读取单独授权。 |
| C-OPS-02 | 验证学生入口 | 练习提交门禁、考试结果发布门禁 | 学生AI请求校验本题已提交且为练习场景；考试期间及考试结果页面不新增对话入口。不能靠客户端传来的已提交字段授权。 |
| C-OPS-03 | 查看分析任务 | 出题、练习问答、简答评分、转写、教学分析 | 展示对象、输入版本、状态、更新时间和错误，元数据权限不等于病史／答案／音频读取权。 |
| C-OPS-04 | 重试与处理失败 | 重试、限流提示和任务历史 | 按任务与输入版本去重；有限重试，认证或余额问题交管理员处理，不无限调用，不以0分替代失败。 |
| C-OPS-05 | 维护日志与预算 | 必要审计、用量和额度状态 | 只记必要追踪信息，不记密码、密钥、全文病史或音频；触达限额暂停新调用并说明，不能承诺未确认预算足够。 |

## 4. 专项规则与数据关系

任何资料文本、题干、学生答案及转写都是分析输入，不是授权指令。生成失败可存草稿，转写失败不能生成有效录音结论；模型结果不能直接越过教师确认或成绩发布。

所有保存反馈必须对应实际写入结果；本机保存不显示已同步云端。修改被引用内容建立新版本，历史记录使用当次快照。未落实医学规则不由开发者或模型自行定为标准。

## 5. 权限与状态

后台操作不包含改分与医学标准修改。任务等待／运行／完成／部分失败／失败／依据不足，页面刷新不重跑计费任务。

真实服务接入时同时校验入口、列表、检索、详情、文件和写入；浏览器演示不能声称具备真实隔离。

## 6. 界面框架

状态筛选与异常列表优先；详情展示输入版本与可授权证据，不默认展开所有敏感正文。

沿用六院绿色Design System与旧平台相关组件；截图示意说明是页面设计要求，不是本轮已完成截图。参考学生旧稿[第10节界面框架](../../../../../../03_Agent方案/切入点需求稿/07_切片图书馆病例模拟作答/学生病理教学模块需求稿_v0.3.1.md#10-界面框架)，仅继承适用布局，不恢复已取消的多选、复杂简答表格及强制标注规则。
