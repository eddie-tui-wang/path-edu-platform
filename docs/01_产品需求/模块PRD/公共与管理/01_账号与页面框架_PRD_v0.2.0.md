# 公共与管理｜账号与页面框架 PRD v0.2.0

## 1. 产品定义

- **这是什么功能：** 提供教师、学生、管理员入口及统一页面操作。
- **帮助用户解决什么问题：** 消除冗余导航和不一致表单按钮，明确不同身份职责。
- **为平台带来什么价值：** 保持独立教学网站的统一体验和身份边界。

> **实施前置依赖：** 真实跨设备身份及数据共享D-F05；不因本轮文档更新购买数据库。 统一见[实施依赖清单](../../../03_实施与进度/实施依赖与待确认清单.md)。已确认产品行为不等于服务已接通或医学效果已验证。

## 2. 产品结构

登录 → 角色侧栏 → 功能模块；管理员账号列表 → 按需编辑。

共用阶段、数据版本与权限原则见[需求总纲](../../需求总纲.md)，模块入口见[目录](../README.md)。

## 3. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| C-ACCOUNT-01 | 进入角色工作区 | 品牌与账号区、角色侧栏 | 顶部仅品牌、身份、改密与退出；删除重复角色顶栏和无效帮助中心。教师与学生侧栏按当前模块目录组织。 |
| C-ACCOUNT-02 | 查看管理列表 | 标题、新增按钮、搜索和表格 | 管理员以账号列表为主，搜索账号／姓名、筛选角色状态，不留空侧栏占位；新建表单不长期挤在列表下。 |
| C-ACCOUNT-03 | 新增与编辑 | 抽屉或对话框、字段校验 | 姓名、账号、角色和初始密码按需填写；成功定位新记录，失败保留输入。当前账号与最后管理员保护。 |
| C-ACCOUNT-04 | 启停和重置 | 行操作与确认反馈 | 停用、角色调整、密码重置明确目标；不允许停用自己或去掉最后可用管理员。演示操作只作用本浏览器。 |
| C-ACCOUNT-05 | 恢复演示账号 | 更多操作内统一按钮及确认 | 使用现有DS组件，不留裸按钮；明确影响账号，默认不清除病例、题库、试卷或答卷。账号密码文档只记录公开演示凭据，不写真实密钥。 |
| C-ACCOUNT-06 | 统一提示和响应 | 简短来源标签、保存错误和焦点 | 去除重复固定流程横幅；必要患者隐私告知保留。正文16px、辅助14px，窄屏重排、200%缩放与键盘焦点可见。 |

## 4. 专项规则与数据关系

浏览器演示身份不是服务端安全隔离。真实账号服务后续继续使用独立系统，密码单向哈希，密钥不进入前端。当前改稿不触碰已有账号或凭据。

所有保存反馈必须对应实际写入结果；本机保存不显示已同步云端。修改被引用内容建立新版本，历史记录使用当次快照。未落实医学规则不由开发者或模型自行定为标准。

## 5. 权限与状态

管理员管账号，教师管授权教学对象，学生管本人作答；管理账号不自动给医学资料权。账号启用／停用／待改密；本机记录不称安全审计。

真实服务接入时同时校验入口、列表、检索、详情、文件和写入；浏览器演示不能声称具备真实隔离。

## 6. 界面框架

列表优先、表单按需；统一按钮尺寸、危险操作层级、弹窗焦点和操作反馈。四条浏览器意见保持有效。

沿用六院绿色Design System与旧平台相关组件；截图示意说明是页面设计要求，不是本轮已完成截图。参考学生旧稿[第10节界面框架](../../../../../../03_Agent方案/切入点需求稿/07_切片图书馆病例模拟作答/学生病理教学模块需求稿_v0.3.1.md#10-界面框架)，仅继承适用布局，不恢复已取消的多选、复杂简答表格及强制标注规则。
