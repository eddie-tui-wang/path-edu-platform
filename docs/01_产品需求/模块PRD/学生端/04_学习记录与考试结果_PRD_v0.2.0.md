# 学生端｜学习记录与考试结果 PRD v0.2.0

## 1. 产品定义

- **这是什么功能：** 分别回看日常练习与已发布考试结果，并追溯原始答案。
- **帮助用户解决什么问题：** 避免把练习即时反馈误认为考试正式成绩。
- **为平台带来什么价值：** 提供版本一致的个人学习历史。

> **实施前置依赖：** 真实历史共享依赖D-F05；当前本机演示不可承诺跨设备恢复。 统一见[实施依赖清单](../../../03_实施与进度/实施依赖与待确认清单.md)。已确认产品行为不等于服务已接通或医学效果已验证。

## 2. 产品结构

学习记录 → 练习／考试筛选 → 详情 → 原答和参考 → 图片证据。

共用阶段、数据版本与权限原则见[需求总纲](../../需求总纲.md)，模块入口见[目录](../README.md)。

## 3. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| S-RESULT-01 | 查询记录 | 练习／考试标签、时间与状态筛选 | 明确来源类型；练习记录关联题目，考试记录关联整卷。仅本人，空数据展示空态，不默认种入已完成考试。 |
| S-RESULT-02 | 回看练习 | 单题答案、教师解析与AI对话记录 | 已提交后可查看本次选项或文字、教师解析；AI反馈标清来源，不能覆盖预设答案或原文。 |
| S-RESULT-03 | 查看考试结果 | 待发布状态或成绩总览 | 教师整场发布后开放题分、总分与参考；未发布只展示提交及处理状态。不因练习同题已提交而解锁考试成绩。 |
| S-RESULT-04 | 逐题对照 | 原答案、参考与评分点评 | 使用当次选项顺序、文本格式、题目及图片快照；简答显示评分点及复核理由，缺失依据显示缺失。 |
| S-RESULT-05 | 定位图片与修正 | 图像入口、结果版本和修正说明 | 打开历史图片；成绩修正后显示最新已发布版本和原因，保留原版。不把当前题库更改应用于历史记录。 |

## 4. 专项规则与数据关系

练习可复习其提交时解析，考试遵守教师发布门禁。记录保存场景、学生、题目／试卷、病例、参考和规则版本；练习无正式考试总分时不编造。

所有保存反馈必须对应实际写入结果；本机保存不显示已同步云端。修改被引用内容建立新版本，历史记录使用当次快照。未落实医学规则不由开发者或模型自行定为标准。

## 5. 权限与状态

仅本人数据，任何详情请求都检查归属与发布状态。加载／无记录／待发布／已发布／失败分别展示，学生不能修改原答或删改评分。

真实服务接入时同时校验入口、列表、检索、详情、文件和写入；浏览器演示不能声称具备真实隔离。

## 6. 界面框架

先来源标签与列表，后结果总览，再逐题详情；沿用旧结果对照方式，保留返回筛选和题目。

沿用六院绿色Design System与旧平台相关组件；截图示意说明是页面设计要求，不是本轮已完成截图。参考学生旧稿[第10节界面框架](../../../../../../03_Agent方案/切入点需求稿/07_切片图书馆病例模拟作答/学生病理教学模块需求稿_v0.3.1.md#10-界面框架)，仅继承适用布局，不恢复已取消的多选、复杂简答表格及强制标注规则。
