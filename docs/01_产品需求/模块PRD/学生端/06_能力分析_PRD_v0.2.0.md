# 学生端｜能力分析 PRD v0.2.0

## 1. 产品定义

- **这是什么功能：** 区分练习与考试，展示五维表现、证据与学习建议。
- **帮助用户解决什么问题：** 让学生理解哪些结论来自正式考试，哪些只是练习反馈。
- **为平台带来什么价值：** 形成有来源、有覆盖度的能力记录。

> **实施前置依赖：** 五维指标映射、最低样本和可比性D-F02；默认不自动评价真实医学能力。 统一见[实施依赖清单](../../../03_实施与进度/实施依赖与待确认清单.md)。已确认产品行为不等于服务已接通或医学效果已验证。

## 2. 产品结构

总览 → 考试／练习来源 → 五维证据 → 原题与建议。

共用阶段、数据版本与权限原则见[需求总纲](../../需求总纲.md)，模块入口见[目录](../README.md)。

## 3. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| S-ABILITY-01 | 查看分析范围 | 来源切换、样本量和更新时间 | 考试视图仅已发布且有效结果；练习单独展示，不默认混入正式能力分数或趋势。 |
| S-ABILITY-02 | 查看五维 | 维度卡片和覆盖状态 | 临床信息理解、关键区域识别、形态学判断、诊断与鉴别、辅助检查决策；本期纯文本简答和单选不能默认提供区域定位证据。 |
| S-ABILITY-03 | 展示有效分数与限制 | 规则版本、题型贡献和无数据说明 | 未覆盖维度标未评估而非0分；文字提及区域不能直接充当标注几何能力。权重与样本不足时只呈现事实与证据。 |
| S-ABILITY-04 | 下钻证据 | 具体练习／考试题、原答和参考 | 每项结论可回到来源题目及版本；不跳到无关默认胃部病例。 |
| S-ABILITY-05 | 生成建议与更新 | 问题依据、行动和回看入口 | 建议以已确认错误和足量样本为依据；跨卷不可比不生成虚假进步趋势，重新发布结果后按版本更新。 |

## 4. 专项规则与数据关系

第一期无强制标注，关键区域识别可能长期证据不足，这是正确状态而非功能报错。练习AI提示后的表现不能与无提示考试直接等价。

所有保存反馈必须对应实际写入结果；本机保存不显示已同步云端。修改被引用内容建立新版本，历史记录使用当次快照。未落实医学规则不由开发者或模型自行定为标准。

## 5. 权限与状态

本人查看；未发布考试不参与统计。每维证据不足／规则待确认／可用，分析失败保留上次有效结果与生成时间。

真实服务接入时同时校验入口、列表、检索、详情、文件和写入；浏览器演示不能声称具备真实隔离。

## 6. 界面框架

摘要→五维覆盖→证据与建议；图表不只靠颜色，缺数据不画完整满维雷达。

沿用六院绿色Design System与旧平台相关组件；截图示意说明是页面设计要求，不是本轮已完成截图。参考学生旧稿[第10节界面框架](../../../../../../03_Agent方案/切入点需求稿/07_切片图书馆病例模拟作答/学生病理教学模块需求稿_v0.3.1.md#10-界面框架)，仅继承适用布局，不恢复已取消的多选、复杂简答表格及强制标注规则。
