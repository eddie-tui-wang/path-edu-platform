# 学生端｜日常练习与AI解析 PRD v0.2.0

## 1. 产品定义

- **这是什么功能：** 完成教师开放的单选或简答练习，提交后对照解析并向AI追问。
- **帮助用户解决什么问题：** 将自主做题与解释、复习连在同一阅片页面。
- **为平台带来什么价值：** 产生与考试区分的学习记录和可追溯AI辅导。

> **实施前置依赖：** AI服务与授权解析依据D-F02、D-F03；本地演示仅本机隔离，真实权限依赖服务端，D-F05。 统一见[实施依赖清单](../../../03_实施与进度/实施依赖与待确认清单.md)。已确认产品行为不等于服务已接通或医学效果已验证。

## 2. 产品结构

练习列表／病例入口 → 开始 → 阅片作答 → 提交 → 答案解析与AI对话。

共用阶段、数据版本与权限原则见[需求总纲](../../需求总纲.md)，模块入口见[目录](../README.md)。

## 3. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| S-PRACTICE-01 | 选择练习 | 分类、题型及可做题目列表 | 仅已确认且向本人开放练习的题目；单选或简答。列表不透露正确选项，不用模拟考试分配替代练习开放。 |
| S-PRACTICE-02 | 单选作答 | 旧三栏布局、右侧单选项 | 选择一个选项，未提交可修改；不提供多选。提交前不展示答案、解析或AI入口，也不后台预加载可读取的私有答案。 |
| S-PRACTICE-03 | 简答作答 | 图片、病史及基本文本编辑区 | 阅读题干，在一个文本框内填写诊断、鉴别及必要IHC思路；支持加粗、列表、撤销／重做。第一期不要求多段结构化表格或强制标注，旧阅片工具可保留但不影响完成判定。 |
| S-PRACTICE-04 | 保存与提交 | 保存状态、提交按钮和确认 | 保存当前题文字／选项及阅片位置；有效答案后提交并锁定此次作答。重复提交返回同一记录，保存失败保留输入。 |
| S-PRACTICE-05 | 查看预设答案解析 | 本人答案与教师参考对照 | 单选确定性判断，显示教师确认的正确答案与解析，不等待AI完成。简答显示本人文本和教师参考，AI建议单独标识，不把建议自动作为考试成绩。 |
| S-PRACTICE-06 | 提交后AI追问 | 右侧解析区内的对话标签 | 仅当前练习已提交后开放。AI依据该题病史、教师答案、解析和授权来源解释；回答不能修改教师预设答案或单选得分，不读取其他未提交题答案。 |
| S-PRACTICE-07 | 查看反馈与返回 | 分析状态、证据链接和返回列表 | AI失败不遮挡已有教师解析；返回保留筛选。无来源明确说明无法确认，不编造诊断或文献。此次记录进入学习记录并标练习来源。 |

## 4. 专项规则与数据关系

参考旧PRD第10节：左临床、中图、右作答；提交后右侧转换为答案／解析／AI标签，不额外挤出第四栏。练习不按考试计时或整场等待发布；本轮不新增错题重做、无限重答策略。单选提交即显示解析，AI不是固定解析的替代品。

所有保存反馈必须对应实际写入结果；本机保存不显示已同步云端。修改被引用内容建立新版本，历史记录使用当次快照。未落实医学规则不由开发者或模型自行定为标准。

## 5. 权限与状态

只能本人开放题与本人记录；服务端AI入口验证当前题已提交，不能只隐藏按钮。状态：未开始／作答中／已提交；AI等待／处理中／完成／失败独立，失败不回退提交状态。

真实服务接入时同时校验入口、列表、检索、详情、文件和写入；浏览器演示不能声称具备真实隔离。

## 6. 界面框架

保留旧三栏及底部题目导航风格；简答仅基本文本工具。窄屏采用同一内容的标签切换，不强行缩小整页。

沿用六院绿色Design System与旧平台相关组件；截图示意说明是页面设计要求，不是本轮已完成截图。参考学生旧稿[第10节界面框架](../../../../../../03_Agent方案/切入点需求稿/07_切片图书馆病例模拟作答/学生病理教学模块需求稿_v0.3.1.md#10-界面框架)，仅继承适用布局，不恢复已取消的多选、复杂简答表格及强制标注规则。
