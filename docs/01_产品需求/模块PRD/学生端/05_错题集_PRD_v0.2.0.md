# 学生端｜错题集 PRD v0.2.0

## 1. 产品定义

- **这是什么功能：** 按练习或考试来源归集已确定错误，支持回看解析和切片。
- **帮助用户解决什么问题：** 让学生定位具体错误并避免把未评分当成错误。
- **为平台带来什么价值：** 保持错题与当前有效评分一致。

> **实施前置依赖：** 错误标签及简答有效性规则D-F02；本轮不宣称新来源归集已开发。 统一见[实施依赖清单](../../../03_实施与进度/实施依赖与待确认清单.md)。已确认产品行为不等于服务已接通或医学效果已验证。

## 2. 产品结构

错题列表 → 来源与分类筛选 → 错误详情 → 原题与图片。

共用阶段、数据版本与权限原则见[需求总纲](../../需求总纲.md)，模块入口见[目录](../README.md)。

## 3. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| S-WRONG-01 | 归集错题 | 练习／考试来源与数量 | 练习单选提交判错即可归集；考试只用已发布评分。简答只按有效评分规则确定的错误点归集，参考展示或AI调用失败不算错题。 |
| S-WRONG-02 | 查询与筛选 | 四类部位、题型、能力与来源筛选 | 题型只有单选／简答，分类沿图书馆顺序；有明确错误依据才生成标签，不能按答案长度判断错。 |
| S-WRONG-03 | 查看原答与解析 | 单选原选项或简答原文、错误点 | 明确来自练习还是考试；显示教师预设解析、复核意见和允许的AI说明，互不覆盖。 |
| S-WRONG-04 | 回看切片 | 历史图与对应题目 | 回到当次影像版本；没有作答标注时不捏造红框作为学生证据。 |
| S-WRONG-05 | 跟随更正 | 更新标记与修订记录 | 评分更正后重新归集并保留历史，不重复新增同一错误。本期不增加错题重答或掌握打卡。 |

## 4. 专项规则与数据关系

移除重复示例长横幅，以简短来源标签表达示例；未确定简答错误时不占位填充。错误记录主键包含作答及得分点，避免一题重复统计。

所有保存反馈必须对应实际写入结果；本机保存不显示已同步云端。修改被引用内容建立新版本，历史记录使用当次快照。未落实医学规则不由开发者或模型自行定为标准。

## 5. 权限与状态

仅本人；考试错题遵守结果发布权限。状态：暂无错题／有效错误／因更正不再归集；历史答卷仍可追溯。

真实服务接入时同时校验入口、列表、检索、详情、文件和写入；浏览器演示不能声称具备真实隔离。

## 6. 界面框架

筛选上置、列表为主；详情并列原答与解析，不在列表永久展开整段AI解释。

沿用六院绿色Design System与旧平台相关组件；截图示意说明是页面设计要求，不是本轮已完成截图。参考学生旧稿[第10节界面框架](../../../../../../03_Agent方案/切入点需求稿/07_切片图书馆病例模拟作答/学生病理教学模块需求稿_v0.3.1.md#10-界面框架)，仅继承适用布局，不恢复已取消的多选、复杂简答表格及强制标注规则。
