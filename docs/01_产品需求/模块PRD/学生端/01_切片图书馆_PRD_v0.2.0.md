# 学生端｜切片图书馆 PRD v0.2.1

## 1. 产品定义

- **这是什么功能：** 按四类优先部位及原有分类检索、收藏和浏览开放的病例与切片。
- **帮助用户解决什么问题：** 方便学生找到目标教学材料并进入相关练习。
- **为平台带来什么价值：** 让图书馆成为学习与题库共用的资料入口。

> **实施前置依赖：** 四类素材数量、授权与开放字段依赖D-F01；没有某类真实素材不暗示医学覆盖完整。 统一见[实施依赖清单](../../../03_实施与进度/实施依赖与待确认清单.md)。已确认产品行为不等于服务已接通或医学效果已验证。

## 2. 产品结构

全部切片／收藏 → 分类与来源筛选 → 病例详情 → 阅片／关联练习。

共用阶段、数据版本与权限原则见[需求总纲](../../需求总纲.md)，模块入口见[目录](../README.md)。

## 3. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| S-LIB-01 | 进入图书馆 | 四类分类条与病例列表 | 固定顺序：骨与软组织肿瘤／肉瘤、甲状腺肿瘤／甲状腺癌、前列腺癌／泌尿系统肿瘤、妇科肿瘤，其后保留胃、乳腺、结直肠等已有分类。可陈列虚构病例并共用占位图；数量按实际逻辑病例计数，没有记录时显示空态。 |
| S-LIB-02 | 检索与查看收藏 | 来源、关键词、卡片／列表切换 | 标准库和院方库共用体验、分别校验权限。按病例号、部位和已开放诊断检索；收藏按本人保存，切换视图不重置条件。 |
| S-LIB-03 | 查看病例 | 临床病史、检查信息、图片列表 | 展示开放资料，缺项显示未提供。未公开参考答案、教师内部诊断和评分字段不返回学生页面。 |
| S-LIB-04 | 阅片 | 主图、缩略图、平移缩放及返回 | 按所选图片ID读取；普通图片显示相对缩放，不伪造物理倍率。布局和控件参考旧图书馆，返回保留列表位置。 |
| S-LIB-05 | 进入练习 | 该病例已开放题目列表 | 只展示教师确认并开放练习的题目；无题目显示暂无练习。收藏、病例开放、题目开放、考试分配是不同权限，不互相自动授予。 |

## 4. 专项规则与数据关系

学生不上传或编辑病例。为考试保密的题目不能仅靠隐藏详情标题保护：公开资料是否包含答案需教师发布检查；已经学习过的病例不可承诺未知盲测。

所有保存反馈必须对应实际写入结果；本机保存不显示已同步云端。修改被引用内容建立新版本，历史记录使用当次快照。未落实医学规则不由开发者或模型自行定为标准。

## 5. 权限与状态

仅所属或授权范围资料、本人收藏；撤权后不可通过收藏、检索或直接地址继续访问。加载／无结果／无权限／失败分别展示。

真实服务接入时同时校验入口、列表、检索、详情、文件和写入；浏览器演示不能声称具备真实隔离。

## 6. 界面框架

分类与筛选在上，资料卡片或列表在下；详情沿用旧库阅片框架，不插入重复说明横幅。

沿用六院绿色Design System与旧平台相关组件；截图示意说明是页面设计要求，不是本轮已完成截图。参考学生旧稿[第10节界面框架](../../../../../../03_Agent方案/切入点需求稿/07_切片图书馆病例模拟作答/学生病理教学模块需求稿_v0.3.1.md#10-界面框架)，仅继承适用布局，不恢复已取消的多选、复杂简答表格及强制标注规则。
