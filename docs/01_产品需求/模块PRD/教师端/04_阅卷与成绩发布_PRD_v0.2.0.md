# 教师端｜阅卷与成绩发布 PRD v0.2.0

## 1. 产品定义

- **这是什么功能：** 查看模拟考试答卷，复核简答评分并发布学生成绩。
- **帮助用户解决什么问题：** 把学生原答、参考依据、初评和最终评分放在同一工作区。
- **为平台带来什么价值：** 提供可追溯成绩及学生复习数据。

> **实施前置依赖：** 专家简答评分点、AI结构校验与规则版本待落实；可人工评分完成流程，医学质量验收独立。D-F02、D-F03。 统一见[实施依赖清单](../../../03_实施与进度/实施依赖与待确认清单.md)。已确认产品行为不等于服务已接通或医学效果已验证。

## 2. 产品结构

考试 → 提交名单 → 答卷与参考 → 逐题评分 → 整场发布 → 修正记录。

共用阶段、数据版本与权限原则见[需求总纲](../../需求总纲.md)，模块入口见[目录](../README.md)。

## 3. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| T-GRADE-01 | 选择考试与学生 | 考试摘要、提交名单及状态筛选 | 展示未开始、进行中、已提交及待处理数；只对已提交答卷阅卷，不把未交卷算成零分答卷。 |
| T-GRADE-02 | 查看原答 | 病例信息、图片和只读答案 | 使用提交时快照；单选显示所选项，简答显示文本和格式，不能编辑学生原文。 |
| T-GRADE-03 | 计算与分析 | 单选程序得分、简答逐点评分建议 | 单选按冻结正确项确定性计分；简答AI按参考和评分点给建议、引用与待确认项。无服务或失败转待人工处理，不假造AI结果。 |
| T-GRADE-04 | 人工复核 | 参考答案、评分点、分数和点评 | 教师确认或修改简答得分；分数在题分范围内，修改须记录理由。合理但标准无法确认的内容交教师判断，不直接判错。 |
| T-GRADE-05 | 发布考试结果 | 待处理清单、整场发布确认 | 所有已提交且需处理答卷完成评分复核后才能发布；未交卷不阻止对已交卷发布。学生此前只见提交状态，发布后见分数、参考和解析。 |
| T-GRADE-06 | 修正与更新 | 修正原因、前后分数及结果版本 | 更正产生新版本并保留原评分和原答；重新发布后记录、错题和能力分析跟随同一版本，避免重复统计。 |

## 4. 专项规则与数据关系

此模块批阅学生试卷，与教师讲课录音分析完全独立。空答可计0，服务失败≠0。选择题参考错误应通过受控纠错与重新评分记录处理，不由模型擅改标准。练习提交后即时公开解析的规则不套用于考试。

所有保存反馈必须对应实际写入结果；本机保存不显示已同步云端。修改被引用内容建立新版本，历史记录使用当次快照。未落实医学规则不由开发者或模型自行定为标准。

## 5. 权限与状态

授权教师只能阅自己的／授权考试；管理员不能默认改分。评分：待分析／待复核／已复核，结果：待发布／已发布；发布校验不依赖虚假的AI完成状态。

真实服务接入时同时校验入口、列表、检索、详情、文件和写入；浏览器演示不能声称具备真实隔离。

## 6. 界面框架

左学生与题目导航，中图片和原答，右参考、评分点和点评；固定保存／下一份／发布入口，保留当前阅卷位置。

沿用六院绿色Design System与旧平台相关组件；截图示意说明是页面设计要求，不是本轮已完成截图。参考学生旧稿[第10节界面框架](../../../../../../03_Agent方案/切入点需求稿/07_切片图书馆病例模拟作答/学生病理教学模块需求稿_v0.3.1.md#10-界面框架)，仅继承适用布局，不恢复已取消的多选、复杂简答表格及强制标注规则。
