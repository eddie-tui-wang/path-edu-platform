# 教师端｜题库与出题 PRD v0.2.0

## 1. 产品定义

- **这是什么功能：** 教师选片后生成并调整单选题，或编写简答题，确认后存入题库。
- **帮助用户解决什么问题：** 让题目编辑与组卷分开，已确认题目可重复用于练习和考试。
- **为平台带来什么价值：** 沉淀与切片及医学依据关联的可复用题库。

> **实施前置依赖：** DeepSeek服务端调用、病例资料及专家确认是生成依赖；未配置服务不能以计时器假成功。D-F02、D-F03。 统一见[实施依赖清单](../../../03_实施与进度/实施依赖与待确认清单.md)。已确认产品行为不等于服务已接通或医学效果已验证。

## 2. 产品结构

题库列表 → 选择切片 → 选择单选／简答 → 编辑与预览 → 确认入库 → 开放练习或用于组卷。

共用阶段、数据版本与权限原则见[需求总纲](../../需求总纲.md)，模块入口见[目录](../README.md)。

## 3. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| T-QUESTION-01 | 选择切片和题型 | 资料选择器、已选图与单选／简答切换 | 可从图书馆或题库新建入口发起；选取授权病例及对应片子，确认可用病史和参考资料。第一期仅单选和简答，不显示多选配置。 |
| T-QUESTION-02 | 生成单选草稿 | 生成按钮、进度、材料依据和题目卡片 | 教师确认选片及材料后触发AI；根据关联病史、参考诊断和知识片段生成题干、选项、唯一正确答案和解析。文本模型不默认直接判读切片。 |
| T-QUESTION-03 | 调整问卷式题卡 | 题干、可增删重排选项、正确项和解析编辑 | 采用问卷产品常见编辑方式：题卡编辑、选项维护、选择正确项、复制草稿和预览。教师可修改全部生成内容；不引入问卷逻辑跳转、满意度量表或通用问卷模板市场。 |
| T-QUESTION-04 | 编写简答题 | 切片与病史预览、题干、参考答案、评分点 | 教师填写诊断、鉴别和必要IHC等作答要求；学生将使用一个文本编辑区，不生成多项疾病／抗体结构化表格。本期不默认AI生成简答题。 |
| T-QUESTION-05 | 预览与验证 | 学生预览及字段问题定位 | 学生预览只看图片、开放病史、题干和选项或文本框；校验单选至少两个非空选项且仅一个正确项、答案有效、解析齐备；简答校验参考答案与评分点。 |
| T-QUESTION-06 | 教师确认入库 | 确认摘要、保存状态和题目版本 | AI生成不等于入库。教师核对医学依据并确认，记录确认人与版本；不完整内容可存草稿但不能进入可用题库。 |
| T-QUESTION-07 | 组织与开放题目 | 题库筛选、练习开放开关和用于组卷 | 按分类、题型、状态检索；确认题可用于组卷。教师明确开放练习后学生才可做题，不因入库自动公开。已用于考试且公开练习的题有重复曝光提示。 |
| T-QUESTION-08 | 维护版本 | 复制编辑、停用和引用记录 | 重生成先确认是否替换当前草稿，避免覆盖人工修改；已被练习或试卷使用的题目生成新版本。停用阻止新引用，保留历史作答。 |

## 4. 专项规则与数据关系

单选只保存一个正确选项，学生只能选一个。选项删除／重排后答案按稳定选项ID关联，不能按字母误移。解析以教师确认版本为准，AI追问不能改答案。简答评分点保存文字说明、分值占比及能力映射；组卷配置题分后明确换算，不隐藏加权。题目开放练习与试卷发放是两种独立发布行为。

所有保存反馈必须对应实际写入结果；本机保存不显示已同步云端。修改被引用内容建立新版本，历史记录使用当次快照。未落实医学规则不由开发者或模型自行定为标准。

## 5. 权限与状态

仅授权教师生成、编辑、确认和开放题；学生不能读取未开放题及参考字段。状态：草稿／生成中／生成失败／待确认／已确认／已停用；生成失败保留已有内容，可重试或手动编写。

真实服务接入时同时校验入口、列表、检索、详情、文件和写入；浏览器演示不能声称具备真实隔离。

## 6. 界面框架

参考问卷式题卡：左题库或题卡导航，中题干与选项／简答配置，右折叠病例依据和学生预览；保存与确认位置固定。只复用交互模式，不承诺完整复制某产品。

沿用六院绿色Design System与旧平台相关组件；截图示意说明是页面设计要求，不是本轮已完成截图。参考学生旧稿[第10节界面框架](../../../../../../03_Agent方案/切入点需求稿/07_切片图书馆病例模拟作答/学生病理教学模块需求稿_v0.3.1.md#10-界面框架)，仅继承适用布局，不恢复已取消的多选、复杂简答表格及强制标注规则。
