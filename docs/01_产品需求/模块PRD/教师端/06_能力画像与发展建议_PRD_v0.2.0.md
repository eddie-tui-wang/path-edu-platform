# 教师端｜能力画像与发展建议 PRD v0.2.0

## 1. 产品定义

- **这是什么功能：** 结合教学分析、实际AI使用及资源贡献展示四维画像和改进建议。
- **帮助用户解决什么问题：** 把教学分析变成具体可行动建议，而非一个不可解释总分。
- **为平台带来什么价值：** 沉淀教师发展证据并支持版本追溯。

> **实施前置依赖：** 专家四维指标与采纳修订评价标准，D-F02；AI服务D-F03。 统一见[实施依赖清单](../../../03_实施与进度/实施依赖与待确认清单.md)。已确认产品行为不等于服务已接通或医学效果已验证。

## 2. 产品结构

四维总览 → 维度证据 → 原始记录 → 建议与验证方式。

共用阶段、数据版本与权限原则见[需求总纲](../../需求总纲.md)，模块入口见[目录](../README.md)。

## 3. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| T-ABILITY-01 | 查看总览 | 四维卡片、统计范围和证据量 | 专业知识、教学技能、AI应用、资源建设分别展示；缺少证据的维度独立标不足，不用一次录音填满四维分数。 |
| T-ABILITY-02 | 下钻知识与教学证据 | 相关录音、诊断一致性和互动记录 | 结论必须引用时间戳和参考来源；没有已确认医学资料不能以表达流畅程度代替专业知识准确性。 |
| T-ABILITY-03 | 查看AI应用证据 | 实际生成调用、教师调整与确认记录 | 题库AI生成与教师修订可作为实际应用记录；仅使用次数或API调用量不等于能力强，具体指标由专家确认。 |
| T-ABILITY-04 | 查看资源建设证据 | 本人确认题目、病例及版本贡献 | 按真实作者和确认记录汇总；浏览或收藏他人资料不是资源建设，发布同一题多次不能重复算贡献。 |
| T-ABILITY-05 | 阅读发展建议 | 证据→改进动作→应用场景→验证方式 | 建议回链录音、题目或病例；无模型时可展示事实统计，不能伪装AI建议。 |
| T-ABILITY-06 | 更新历史 | 规则、结果版本及更新时间 | 新有效证据或原文校订后重新计算；保留历史，不在不同比较规则间直接宣称成长。 |

## 4. 专项规则与数据关系

程序负责统计，AI负责有来源的解释。四维最低证据量、权重和可比性未确认前不展示权威分数；不增加教师排名、奖惩或证书。

所有保存反馈必须对应实际写入结果；本机保存不显示已同步云端。修改被引用内容建立新版本，历史记录使用当次快照。未落实医学规则不由开发者或模型自行定为标准。

## 5. 权限与状态

教师查看本人，其他教师画像单独授权；管理员无默认内容权。各维度分别为证据不足／规则待确认／可用；任务失败保留上次有效结果及时间。

真实服务接入时同时校验入口、列表、检索、详情、文件和写入；浏览器演示不能声称具备真实隔离。

## 6. 界面框架

总览四维卡片配证据数量，详情按维度下钻；建议和证据相邻，避免大雷达图遮蔽数据不足。

沿用六院绿色Design System与旧平台相关组件；截图示意说明是页面设计要求，不是本轮已完成截图。参考学生旧稿[第10节界面框架](../../../../../../03_Agent方案/切入点需求稿/07_切片图书馆病例模拟作答/学生病理教学模块需求稿_v0.3.1.md#10-界面框架)，仅继承适用布局，不恢复已取消的多选、复杂简答表格及强制标注规则。
