# 教师端｜录音与教学分析 PRD v0.2.1

## 1. 产品定义

- **这是什么功能：** 当前以录音演示按钮触发固定多维分析结果，完整呈现教师教学分析流程。
- **帮助用户解决什么问题：** 无需等待录音和转写服务即可体验分析入口、结果及证据回看。
- **为平台带来什么价值：** 验证教学分析交互，为后续真实API接入明确输入输出位置。

> **实施前置依赖：** 当前不依赖音频、麦克风、ASR或AI服务。真实录音上传、转写及医学分析后续按D-F02—D-F04落实，统一见[实施依赖清单](../../../03_实施与进度/实施依赖与待确认清单.md)。

## 2. 产品结构

教学记录 → 点击录音演示 → 预设分析结论 → 三类分析及四维示例 → 返回记录。

共用规则见[需求总纲](../../需求总纲.md)，模块入口见[目录](../README.md)。

## 3. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| T-AUDIO-01 | 进入录音演示 | 教学记录及录音演示主按钮 | 点击后直接展示统一预设结果；按钮不申请麦克风、不读取本地文件、不上传音频、不消耗API额度。 |
| T-AUDIO-02 | 查看结论摘要 | 主题、固定结论及示例标签 | 显示预设教学主题和多维结果，以简短“示例”标记，不显示真实转写成功、上传成功或医学评价通过。 |
| T-AUDIO-03 | 查看互动问答 | 问题、回应及点评卡片 | 采用统一预设问答，展开查看点评。此处是演示内容，不冒充实际学生对话。 |
| T-AUDIO-04 | 查看诊断一致性 | 讲解观点、参考观点及差异卡 | 显示预设对比与解释，不计算教师本人真实医学正确率。 |
| T-AUDIO-05 | 查看讲解轨迹 | 预设讲解阶段与示例图片区域 | 可以展示预设顺序和区域，标明示例；不把示例坐标称为真实操作采集，不提供伪造音画同步。 |
| T-AUDIO-06 | 查看多维结果 | 专业知识、教学技能、AI应用、资源建设示例 | 固定结论用于体验布局及下钻；和真实记录、成绩、画像统计分开，不能因点一次按钮而增加真实能力分数。 |
| T-AUDIO-07 | 回看与再次体验 | 返回记录、再次打开结果 | 保持相同示例版本与结果，不随机编造分数；不新增重复真实分析任务。 |

## 4. 专项规则与数据关系

当前演示数据携带来源为示例、示例ID和版本；统一维护预设文本，避免各页面结果不一致。最新用户确认替代上一版“真实上传与ASR为首期前提”的要求。

后续接入真实API时，再启用文件上传、格式大小校验、持久化、带时间戳转写、术语校订、分析任务及证据回放；原音频和校订版本分别保留。服务失败、依据不足与正常完成区分，不用预设结果代替真实任务失败。无真实阅片事件时不输出真实图片轨迹。真实四维评价依赖各自有效证据，不能只用录音补齐所有维度。

## 5. 权限与状态

教师入口可查看示例，学生不开放教师分析页。当前状态为未打开／示例结果；真实服务的上传中、转写中、待校订、分析中、完成、部分失败及依据不足留在后续接入阶段。

示例不能进入真实画像统计。后续真实录音与结论限本人或明确授权，不能以本浏览器角色判断声称真实安全隔离。

## 6. 界面框架

主操作“录音演示”；详情先摘要，再用标签切换讲解轨迹、互动问答、诊断一致性及四维示例。沿用六院绿色Design System，预设内容以简短标签说明，不增加重复解释横幅。未接音频时不显示可操作的假播放器。
