# 旧平台迁移对照

版本 v0.2.1／P0，2026-09-09。2026-09-11 文档整理时，原《旧新模块对应与改稿检查》并入本文（两者同属旧→新迁移映射，避免同一信息分散在两个文件）。本轮不执行代码迁移。

## 1. 旧新模块对应

| 整理前 | 当前承接 |
|---|---|
| 教师病理资料与参考答案 | 教师01切片图书馆与参考资料 |
| 教师考试管理 | 教师02题库与出题＋03试卷管理与发放＋04阅卷与成绩发布 |
| 教师教学记录与三类分析 | 教师05录音上传与教学分析；图像轨迹无事件则不足 |
| 教师能力画像 | 教师06，四维证据不从单录音强补 |
| 学生病理资料 | 学生01，四类排序与关联练习 |
| 学生考试中心与作答 | 学生02日常练习＋03教师发放模拟考 |
| 学生记录、错题、能力 | 学生04—06，明确练习／考试来源 |
| 公共账号及授权后台 | 公共01—02，扩展生成／开放／发卷／提交后AI门禁 |

替换规则：手工单一路径出题→单选AI草稿后教师确认；卷内出题→独立题库组卷；多选→首期移除；固定结构简答与必需标注→基本文本；考试式等待用于所有答题→练习即时解析与考试发布分开；录音当前按钮→固定结果演示，后续API接入再真实转写分析；旧6题样卷→单选练习及10片模拟卷规格。

所有14份模块稿包含三项产品定义、产品结构、四列流程表、专项规则、权限状态、界面框架与实施依赖。总纲维护跨模块规则；配套AI／测试／迁移／依赖文件同步为v0.2.1。旧版模块稿已整体移入 `docs/99_归档/历史版本/`，不与新版平行作为需求。

## 2. 答题界面基准

直接依据[旧学生PRD v0.3.1第10节](../../../../../../03_Agent方案/切入点需求稿/07_切片图书馆病例模拟作答/学生病理教学模块需求稿_v0.3.1.md#10-界面框架)：左侧病例与病史、中间阅片、右侧作答，底部病例题目目录及操作。源实现核查线索为旧科研原型app/teaching-module.tsx；迁移前记录实际组件和截图，不只凭新站类似页面断言原样迁回。

| 旧设计 | 新版保留／调整 |
|---|---|
| 左侧病史临床资料 | 保留分组与布局；未提供不补造 |
| 中间Viewer、图像切换、视野恢复 | 保留；JPG／PNG只显示相对缩放，WSI倍率延后 |
| 右侧单选／多选／简答动态渲染 | 保留同一面板，第一期删除多选；简答仅一个基本文本编辑区 |
| 标注卡片和复杂诊断／鉴别／IHC表格 | 不作为第一期必答，旧基本阅片工具可保留；复杂结构表不恢复 |
| 底部题目导航、检查、提交和计时 | 考试保留；练习按当前题提交，不照搬考试计时和等待发布 |
| 结果及切片对照 | 保留；练习即时教师解析＋右侧AI标签，考试等待发布且无AI对话 |

AI在右侧提交后使用解析／对话标签，不新建挤压阅片的第四列。原样迁移遵循最新规则，不恢复与本轮简化冲突的旧控件。窄屏按原有信息层级折叠，保持200%缩放可用。

## 3. 图书馆迁移

旧app/pathology-platform.tsx的SlideLibraryScreen已有分类、搜索、来源、收藏及卡片／列表交互；此前静态核查发现12条生成记录共用同图、分类计数硬编码、分页静态文本、详情只通知、阅片回调不传ID。病例ID关联、实际计数、分页和详情需重建，不算原有真实后台能力；按最新确认，占位图共用可保留。

| 能力 | 处理与检查 |
|---|---|
| 分类与来源 | 四类置顶，之后保留原有部位，保留标准／院方库来源，数量按实际授权资料 |
| 搜索与双视图 | 保留筛选和滚动，学生不搜索私有诊断字段 |
| 收藏 | 按账号持久化，撤权后不能通过收藏绕过 |
| 详情与阅片 | 真实绑定病例和影像版本；多图对应正确资源，返回保留上下文 |
| 分页 | 数据驱动，无数据不展示假页码 |
| 资料编辑与用于出题 | 接独立平台授权病例及题库，不覆盖已发卷快照 |

完整迁移的是教学图书馆功能，非科研项目／GPU／PACS／训练业务，也不改变旧平台部署。素材、未知旧页面和实际参考截图见D-F01、D-F06；第一期不要求WSI。
