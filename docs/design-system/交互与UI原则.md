# 病理教学平台交互与UI原则

版本：1.0 · 2026-09-10。依据：用户9条页面批注、现有师生流程和两个外部设计技能。本版是后续实施约束，不表示所有旧页面已符合。

## 1. 产品设计方向

使用者：教师在看完教学切片后准备题目、组卷、阅卷；学生在拿到病史和图片后观察、作答、回看反馈。界面应让人专注证据和决策，而不是解释产品内部实现。

领域词：病例、病史、切片、形态、鉴别诊断、评分依据、教学记录、答卷。视觉方向：六院绿色品牌、白色纸面、浅灰绿工作区、深绿文字、琥珀警告、红色错误；病理图像自身的粉紫色保留原貌，不用于装饰按钮。

产品特征：病例—图片—题目—原答—点评的证据连续性。拒绝无依据雷达图、铺满屏幕的分类卡、重复业务入口。分别用可追溯的证据列表、集中筛选、唯一任务归属替代。

## 2. 十二条强制原则

| 编号 | 原则 | 项目规则与验收方式 |
|---|---|---|
| DS-01 | 先任务，后装饰 | 每页一句话回答“我在看什么、能做什么”。第一屏先页面标题与对象，再关键动作，不让概览卡先于对象名称出现。 |
| DS-02 | 一项业务一个主入口 | 录音分析归教学记录；能力分析只聚合结果与回看证据，不再复制创建入口。跨页可链接到主入口，但不独立运行第二套流程。 |
| DS-03 | 动作、筛选、内容分区 | 页头为标题和业务动作；下一行为搜索、部位、来源等筛选；下方为结果。新建、录音、开展教学不放筛选栏。视图切换放结果工具区，并与筛选形成间隔。 |
| DS-04 | 按规模设计筛选 | 部位不展开成20张卡。使用“部位：全部 ▾”触发器，弹层支持搜索、滚动、已选状态、全部部位及清除。保留四类优先顺序和旧分类。当前单选语义不擅自改多选；“多种部位展示”不等于多选需求。 |
| DS-05 | 按钮必须对应明确状态变化 | 保存草稿只持久化未完成内容；预览只读；确认入库改变可用状态；返回只导航。一个区域最多一个主按钮。不能用含糊“结束编辑”承载清除未保存内容。 |
| DS-06 | 卡片必须有解释价值 | 能力结论必须交代对象、时间范围、依据和后续动作。跨次四维画像归能力总览；单次记录只给“本次教学反馈”。无法建立本次证据的四维摘要从详情移除，不填空卡。 |
| DS-07 | 状态只出现一次 | 分析详情已用三个标签导航，不再重复三张“已完成”卡。正常状态在标题旁简写；处理中、失败或部分失败才在对应标签上标识并提供恢复入口。 |
| DS-08 | 导航不重复 | 一级模块不设“返回病例资料”；有侧栏定位已足够。详情可返回其来源列表，保留筛选、页码、滚动位置；不能返回无关模块。 |
| DS-09 | 文案减噪但保持真实 | 删除“以下为预设……不代表……”等重复整段解释，收敛为一个“示例”标签及必要说明。保存失败、清除数据、交卷锁定、未接入服务等会改变用户判断的提示不能删除；不能以去文案让预设结果看起来像真实AI。 |
| DS-10 | 组件一致而非处处定制 | 同类按钮、筛选器、输入框在师生端共享尺寸、间距、颜色、焦点和禁用规则。避免修改一个页面的select却保留其他页面旧样式。 |
| DS-11 | 数据不足也是有效状态 | 未评估不等于0分，不用五张空卡挤占首屏。显示简洁状态及已有证据；未发布考试不混入能力分析。筛选无结果与从未产生记录须区别处理。 |
| DS-12 | 交互完整才算完成 | 键盘可达、保存状态可知、失败可重试、切换可恢复、窄屏可操作。发布与清除二次确认；预览不改数据；编辑失败不丢原答。 |

## 3. 页面骨架

列表页：页面标题＋唯一主动作 → 集中筛选条 → 当前条件／结果数及视图切换 → 列表或卡片 → 分页。

编辑页：标题＋返回 → 材料上下文与编辑区 → 保存状态 → 草稿／主提交操作。预览使用有标题的只读面板，关闭后焦点返回原按钮。

教学记录详情：返回教学记录＋记录标题／日期／单一总状态 → 三类分析标签 → 本次证据及点评。四维长期画像不置顶重复展示。

能力总览：对象和统计时间 → 有依据的汇总与不足说明 → 维度证据 → 改进建议。只有真实可追溯数据才显示数值趋势。

## 4. 组件规则

### 筛选器

- 小规模固定项（来源、题型）：优先封装原生select并统一外观，保留系统键盘及移动端行为。触发区文字＋向下箭头，不能仅靠颜色表示可点击。
- 20种以上部位：可搜索单选弹层；最大高度约320px、内部滚动；输入搜索词不立即改变外层筛选，选定才更新；选中后第一页刷新，返回列表保留条件。
- 长标签允许弹层内换行；触发器可截断但能获知完整选项。无匹配项展示“没有匹配部位”，清空搜索不清除已选部位。
- 统一默认、悬停、展开、焦点、选中、禁用、错误、空态；Escape关闭、Tab不困住焦点、方向键与Enter可选、关闭回到触发器。自定义时使用正确combobox/listbox语义，不用无语义div冒充控件。
- 搜索／部位／来源联合作用；清空筛选清除这三项但不改变“我的收藏”范围或卡片／列表偏好。部位数量不能误算为当前结果数量。

### 操作按钮与题库编辑

| 动作 | 保留方式 | 行为 |
|---|---|---|
| 保存草稿 | 次按钮，底部 | 允许未填完；成功显示保存时间；未修改不产生新版本。保存后不自动开放练习。 |
| 学生预览 | 工具动作，编辑标题旁 | 只读显示当前题干、病史、图片、选项，不展示教师参考；明确“关闭预览”。 |
| 确认入库 | 唯一主按钮，底部 | 校验必填内容、正确项及评分规则，成功返回题库并定位该题；不等于发卷或开放练习。 |
| 返回题库 | 唯一导航出口，顶部 | 无改动直接返回；有改动询问保存草稿／放弃修改／继续编辑。 |
| 结束编辑 | 删除独立按钮 | 当前实质是清除暂存，与返回重复又有数据损失风险；并入返回时的“放弃修改”。 |

确认过的题修改时必须清楚标注“编辑新版本”；保存新草稿不能悄悄让旧可用版本消失或停止练习。该项涉及状态逻辑，需业务回归，不是仅改按钮文案。

### 视觉基础

- 沿用现有绿色token：primary #007c57，primary-strong #005e42，primary-soft #eaf5ef，text #203b32，muted #5d7067，surface #ffffff，border #d8e6df；这是产品配色，不称医院官方VI。
- 以4px为间距基数；标签与控件8px、同组12–16px、区块24–32px。控件8px圆角、内容容器12px，轻边框为主要分层方式，阴影仅用于浮层。
- 正文与表单建议16px，辅助文字14px；页标题24–32px、区块标题20–24px。关键内容不缩字号来塞进窄列。沿用中文系统字体，数字列使用等宽数字。
- 控件建议44px触达高度；普通文本对比度4.5:1；大文字3:1仅适用于至少24 CSS px常规或约18.7px粗体；交互边界与焦点3:1。需实测，不从颜色名称判断通过。
- 品牌绿表示主动作，不承担所有状态；错误、警告用文字配合语义色。医学图像、标注语义色不随品牌重染。
- 在1440、1280、768、390px及200%缩放验收。移动端工具栏折行、筛选弹层不越屏；固定底栏不遮输入和提交；表格必要时自身横滚，不让整页横滚。

## 5. 发布前设计门禁

### 答题交互补充（2026-09-11）

- 练习和考试共用纯文本编辑器：加粗／列表明确叫“标记”；撤销、重做只作用于当前题目，不跨题撤销。当前保留最近100次编辑，刷新仅恢复已保存答案。
- 图片缩放／平移／选图和内容标签按用户、练习题目版本或考试答卷题号隔离；保存在当前标签页，图片资源变化不复用旧视野。视野保存失败与答卷保存失败分别说明。
- 开考与交卷采用原生模态dialog，支持Escape取消和焦点返回；确认必须绑定当前考试动作，不能用另一场残留确认跳过提示；交卷完成或超时后关闭旧确认。
- 考试状态单独展示：未开放、可开始、进行中、截止、待发布、成绩已发布；按钮只表达开始、继续、查看等动作。历史缺时间配置明确标识，不合并成“尚未开放／已结束”。

- [ ] 页面标题、对象、一个主任务在第一屏清楚可见。
- [ ] 业务动作不混进筛选，一级模块没有无意义返回。
- [ ] 20+部位、长名称、空结果及筛选恢复测试通过。
- [ ] 草稿、预览、确认、返回在数据变化上彼此独立。
- [ ] 无重复结论卡／完成卡／免责声明，示例来源仍可辨识。
- [ ] 控件六态、键盘、200%缩放及窄屏检查留下证据。
- [ ] 有证据的数值才显示；未评估、未发布、失败不伪装成成功。

## 6. 外部技能的采用与边界

已学习并安装：[frontend-design-principles](https://github.com/joshuadavidthomas/agent-skills/tree/main/frontend-design-principles)（含app指南、技术原则）；[design-principles](https://github.com/HermeticOrmus/design-mastery-claude-code/tree/main/skills/design-principles)（含评估清单）。使用Codex安装器，不运行额外npx安装包。技能在下一回合可自动发现。

采用任务导向、视觉层级、接近性／相似性、对齐、一致性、克制色彩和完整状态。上述项目规则是结合用户批注重新定义，不是照搬外部文本。

不照搬“所有原生控件都替换”、固定黄金比例、仅为差异化改导航、营销式留白或装饰。优先医院工作流、可读性、无障碍和Ponytail最小实现；既有品牌无需为满足外部token命名风格重新命名。外部指南中的数值是建议，不代表已经测得项目合规。
