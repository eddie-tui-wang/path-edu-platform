# 病理教学 Design System

本目录是独立教学项目的设计规范入口，不修改旧科研平台。业务规则仍以模块PRD为准。

- [交互与UI原则](./交互与UI原则.md)：新增及修改页面必须遵守的设计约束。
- [师生端设计审计](./师生端设计审计_20260910.md)：本轮问题、依据、改造顺序和验收条件。
- 现有实现：`app/migrated.css` 为品牌及文字token，`app/globals.css` 为布局及交互样式，`app/ui-button.tsx` 为共享按钮。当前尚无独立可视化组件展示页；规范写入不等于组件已改造完成。

更新流程：先写页面任务与状态 → 对照原则 → 修改共享组件及页面 → 检查真实界面与键盘交互 → 更新审计状态。不能以编译通过代替交互验收。
