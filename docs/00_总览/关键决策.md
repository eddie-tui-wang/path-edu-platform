## C. 教学业务规则

| 编号 | 决策 | 依据 | 代码执行 |
|---|---|---|---|
| D-18 | **单选是唯一选择题型**（≥2 个非空选项、恰好 1 个正确项，答案绑定选项 ID）；不恢复已被替换的多选 | PRD | 是 |
| D-19 | 四个动作互相独立：**题目确认 / 练习开放 / 组卷发放 / 成绩发布**，任一都不会自动触发下一个 | PRD | 是 |
| D-20 | 模拟出科考试 = **10 个不同影像 ID＋版本**；可共用同一占位文件，重复引用同一影像记录不计数 | PRD | 是（`lib/bank-paper.mjs`） |
| D-21 | 练习与考试严格隔离：考试期间无答案、无 AI；交卷后等教师发布成绩 | PRD | 是 |
| D-22 | 版本冻结：病例、图片、题目、选项顺序、参考、评分点；练习绑题目版本，答卷绑试卷快照 | PRD | 是 |
| D-23 | 计分：单选按冻结正确项确定性计分；简答按教师确认得分点；整卷题分相加，无隐藏权重 | PRD | 是 |
| D-24 | **空答 0 分**；但「调用失败」「依据不足」**不是 0 分** | PRD | 是 |
| D-25 | AI **不改分、不自动发布**成绩；生成题不得跳过教师确认 | AI 说明 | 是（无 AI 调用） |
| D-26 | 未交卷不伪造为「已提交零分卷」 | PRD | 是 |
| D-27 | 录音分析为**按钮触发的预设结果演示**，不采集麦克风、不上传、不调 ASR，与真实画像分开标注 | PRD／依赖清单 | 是 |
| D-28 | 简答错误点归集需专家规则，**未评分不计作错误**，不用分数或 AI 失败反推 | PRD | 是 |
| D-29 | 能力维度（教师四维／学生五维）**未评估不等于 0 分**，无依据不补分、不画雷达 | PRD／设计 | 是 |
