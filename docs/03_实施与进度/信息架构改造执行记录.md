### 最终验证命令

在独立项目目录执行；浏览器脚本使用隔离的公开演示身份、临时浏览器配置，不修改真实账号。

```sh
./node_modules/.bin/tsc --noEmit
node --test tests/*.test.mjs
./node_modules/.bin/next build
node scripts/verify-demo-browser.mjs
node scripts/verify-publishing-browser.mjs
node scripts/verify-navigation-browser.mjs
node scripts/verify-layout-browser.mjs
node scripts/verify-detail-browser.mjs
NATIVE_ZOOM=200 node scripts/verify-detail-browser.mjs
```

测试结果：15/15现有自动化检查、类型检查、构建通过；上述浏览器流程通过。本机浏览器脚本通过PLAYWRIGHT_MODULE指定已安装运行库，不新增依赖。详细脚本还验证教师来源返回、病例草稿恢复、发布检查前进后退／刷新、弹窗关闭后的焦点回归。

原生200%使用独立临时Chrome配置的缩放偏好，实际测得外窗1440、布局视口720、devicePixelRatio=2；不是CSS zoom、设备仿真或仅缩窄窗口。配置格式依据[Chromium缩放偏好实现](https://chromium.googlesource.com/chromium/src/+/lkgr/chrome/browser/ui/zoom/chrome_zoom_level_prefs.cc)。截图使用浏览器原生截图接口，避免普通整页截图在原生缩放下裁切。
