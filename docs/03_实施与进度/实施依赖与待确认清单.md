# 实施依赖与待确认清单 v0.2.1

## 1. 已确认，不重复追问

独立path-edu-platform项目和EdgeOne站点已有；用户确认院外及手机能打开。第一期用JPG／PNG、不用真实WSI，可先本地原型、不购买数据库。DeepSeek已开通；预算上限此前表达为100元以内，具体周期和真实服务开销不自行推定。本次已获准实施原型，不购买和部署。

最新产品确认：单选为唯一选择题类型；问卷式编辑；教师选片后按关联文本生成答案，教师确认入题库；简答基本文本框；从题库组卷，模拟出科10片，由教师发放；AI对话仅练习提交后；讲课录音上传分析与学生阅卷独立；旧学生PRD为界面参考。最新确认：录音先采用按钮触发固定结果的演示流程，真实录音与转写后续评估。四类目录置顶，旧分类保留；虚构病例与同一占位图获准使用。
