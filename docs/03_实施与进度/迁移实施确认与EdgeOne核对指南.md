# 迁移实施确认与 EdgeOne 核对指南 v0.2.0

## 1. 最新确认及适用顺序

本文件是用户后续决定形成的实施增量，优先于v0.1.0文档包的冲突条款；旧PRD和配套原文全部保留。未涉及的功能继续按v0.1.0执行。这里区分“目标MVP”与“本次迁移预览”，不把页面迁移标为后台功能完成。

- **这是什么功能：** 将现有学生与教师教学原型复制适配到独立项目，先运行迁移预览，再逐步实现真实图片教学MVP。
- **帮助用户解决什么问题：** 不等待云资源确认即可推进迁移，同时延后语音转写，避免占用首批交付时间和预算。
- **为平台带来什么价值：** 建立独立开发基线、明确演示与真实功能边界，并保留WSI及教师音频能力的后续迭代路径。

| 已确认事项 | 当前结论 |
|---|---|
| 考试规则 | 用户接受每人每场一份答卷、多选全匹配得分、允许提示后带未答项提交、教师统一发布；这是目标后端规则，迁移原型尚未全部实现。 |
| 开发顺序 | 独立项目与页面迁移 → 账号权限 → 图片上传与阅片 → 考试后端 → DeepSeek；教师真实音频分析延后。 |
| 仓库 | https://github.com/eddie-tui-wang/path-edu-platform.git；迁移前只读检查为空，无已有分支。 |
| 时间 | 越快越好，无固定截止日期；不承诺未经估算的上线日。 |
| 预算 | 按此前月度口径，云资源与AI调用合计100元／月以内；不自动购买或升级。 |
| EdgeOne | 用户截图显示Makers免费版，现有项目model-production-platform，区域显示全球可用区（含中国大陆）；新项目不能复用旧项目身份或覆盖其部署。 |
| DeepSeek | 用户确认已开通；模型额度与服务端密钥配置仍待验证，不能宣称已调用。 |
| ASR与WSI | ASR未开通，后期评估；真实WSI第二期再接入。 |

## 4. 你现在需要做的 EdgeOne 核对

所有步骤只读；遇到“立即开通、创建、升级、付款”先停止，不必点击。

| 顺序 | 如何进入 | 看什么／发给我什么 | 不需要做什么 |
|---|---|---|---|
| 1 | Makers → 项目 → 点击现有model-production-platform → 项目详情／设置 | 项目默认域名或预览地址、自定义域名是否已有、加速区域；发相应截图。若地址注明临时有效，请一并告知。 | 不改旧项目仓库、分支或域名；不将新仓库绑定到旧项目。 |
| 2 | 项目详情内查找“函数／Cloud Functions”及构建设置；菜单名以实际控制台为准 | 是否显示云函数、运行环境、配额／限制，现项目构建框架与Node版本；找不到入口时发完整项目详情菜单。 | 不创建函数，不复制任何环境变量值。 |
| 3 | Makers顶部“存储” → 分别查看KV和Blob | 显示的额度、已有命名空间和是否绑定项目；可以只发概要截图，遮挡业务键名和内容。空列表也正常。 | 不新建命名空间，不改旧数据权限，不上传文件。 |
| 4 | Makers用量／套餐页 | 免费额度是否共享、超额后的处理说明、是否已设置用量告警；发说明截图。 | 不升级套餐，不开启自动付费。 |

你只需发上述截图／文字结论；我负责判断能否用于新网站、哪些还需验证。服务端私有访问、并发写入一致性、备份、数据落地区域和100元预算可行性，由后续技术验证完成，不要求你自行判断。截图避免显示API Token、Secret、患者资料和完整账号信息。

官方核对依据（2026-09-07）：[Makers存储说明](https://pages.edgeone.ai/document/storage-overview)区分KV与Blob；[Blob文档](https://pages.edgeone.ai/document/blob-storage)说明控制台主要用于只读浏览，数据操作通过服务接口完成；[免费额度说明](https://pages.edgeone.ai/document/limits-and-quotas)用于核对限额。内置存储存在不代表它已经满足考试事务、权限与数据驻留要求，暂不替换原数据库方案或承诺全部免费。
