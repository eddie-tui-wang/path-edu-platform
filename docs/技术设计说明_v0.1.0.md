# 病理教学平台技术设计说明（TDD）v0.1.0

日期：2026-09-08；状态：账号子系统本地实现，云端数据库待配置；适用仓库：path-edu-platform。

## 1. 目标、范围与决策

本次对应独立网站 PRD F01、F02、F25 中账号／授权审计部分及第4章 RBAC。旧 PRD 保留，不将本技术实现当成全部 MVP 完成。

- 已实现范围：真实账号创建、登录、首次改密、主动改密、退出、角色组合、停用／启用、管理员重置、资源级授权／撤权、授权审计。
- 未实现范围：真实病例上传、考试发布和作答持久化、真实评分／画像、分析任务后台和 DeepSeek。原页面保留公开合成示例，明确不代表本人数据。
- 教师录音／转写仍为用户确认的演示 UI；WSI 第二期。
- 不开放自注册，不引入班级、收费、第三方登录、验证码短信或邮件服务。
- 当前只有单机构初始化；数据库保留机构字段并做隔离测试，不建设跨机构产品入口。

### ADR-001：Next.js 单体应用，前后端在同一项目

浏览器 UI 与 Node.js 服务端 API 共用仓库、域名和发布版本。减少独立前后端部署、跨域及微服务成本。Next 的“服务端”并不表示浏览器能安全直连数据库：SQL、密钥、密码散列始终只在服务端。

### ADR-002：PostgreSQL 为业务数据库

账号与授权依赖事务、唯一约束及关联查询；后续考试更依赖原子提交和版本一致性。选择关系型 PostgreSQL，不将 KV 或 Blob 当作完整业务数据库。

开发环境使用 PGlite：在 Node 服务进程运行、写入本地文件的 PostgreSQL WASM 实现，不在浏览器运行。生产用 pg 驱动连接独立 PostgreSQL。二者复用 SQL 和业务逻辑，但本地测试不证明线上 TCP/TLS、连接池、多实例并发及备份已验证。

PGlite 在生产被明确拒绝；没有 DATABASE_URL 时接口返回 503，禁止静默退回内存／演示登录。它是单进程本地开发工具，不是 EdgeOne 持久化方案。

### ADR-003：服务端随机会话，而非浏览器声明角色

Cookie 只携带随机令牌，数据库只保存令牌 SHA-256。每次请求查账号有效状态、版本、过期时间；管理操作再查角色和机构。这样停用／撤权不需要等待一个长有效期 JWT 自然到期。

## 2. 软件工程全景：各部分有什么用

| 部分 | 通俗解释 | 本项目选择／状态 |
|---|---|---|
| 产品需求 PRD | 定义做什么、谁能做、什么算完成 | 已有主 PRD；本轮账号按 F01/F02/F25 |
| 前端 UI | 老师、学生、管理员看到并点击的页面 | React；登录、改密、管理员界面真实接 API；教学业务仍演示 |
| 业务后端 API | 判断能否操作，执行规则，保存结果 | Next.js Node 路由；本轮账号 API |
| 身份认证 | 判断“你是谁” | 密码散列、数据库会话、HttpOnly Cookie |
| 权限控制 | 判断“你能对哪条数据做什么” | 角色 + 机构 + 资源授权 + 归属／发布门禁 |
| 关系数据库 | 记录账号、授权；以后存病例元数据、答卷和成绩 | 本地 PGlite；线上 PostgreSQL 待开通 |
| 对象存储 | 放 JPG/PNG、以后放录音和 WSI 大文件 | 待接入私有 Blob/COS；数据库只记文件元数据与引用 |
| AI 服务 | 在依据和规则约束下给出分析建议 | 后续服务端接 DeepSeek；不负责认证或确定性选择题算分 |
| 异步任务 | 用户离开页面后仍继续处理较慢分析 | 后续建设任务状态／重试；不新增队列服务来假装已经完成 |
| 部署与网络 | 让院外浏览器找到网站，并让后端找到数据库 | 用户实测 EdgeOne 预览可访问；独立云 DB 网络仍待验 |
| 配置与密钥 | 不同环境的数据库地址、密码、AI Key | 本地忽略文件；线上服务端环境变量，禁止 NEXT_PUBLIC_ |
| 测试 | 自动与人工发现改动引入的问题 | 账号数据库集成、HTTP边界、类型／构建；云端验收待执行 |
| 日志与监控 | 出问题后能定位，识别失败、异常调用和费用 | 账号审计已实现；正式告警与用量阈值待上线配置 |
| 备份与恢复 | 数据误删或服务坏了能找回 | 云端必须设置备份并做恢复演练；本地文件不是生产备份 |
| 版本管理与发布 | 记录每次变动，知道上线了哪个版本 | Git + 锁文件 + SQL迁移；本轮未自动推送或上线 |

```text

        │ HTTPS，同源请求＋HttpOnly Cookie
        ▼
EdgeOne 网站入口 → Next.js UI ＋ Node.js API
```

## 3. 数据模型

| 表 | 关键字段与约束 | 用途 |
|---|---|---|
| institutions | id、name | 机构边界，由受控初始化创建 |
| users | id、institution_id、唯一 username、display_name、password_hash、roles、active、must_change_password、auth_version | 账号；多个角色以 JSON 数组存储，应用层限定 student/teacher/admin |
| sessions | token_hash、user_id、auth_version、expires_at | 8小时固定有效期；变更后删除会话并更新版本 |
| resource_grants | user_id、resource_type、resource_id、permission、purpose；组合唯一 | 显式资源授权，不允许 *；查看／管理 |
| audit_events | actor_id、target_id、institution_id、action、detail、created_at | 追加式账号审计；无前台删除／修改接口 |
| login_limits | 账号名称散列、失败计数、窗口、锁定期限 | 同账号15分钟内5次失败，锁定15分钟；不存在的账号也计数 |
| schema_migrations | version、applied_at | 版本化 SQL 执行记录 |

密码使用随机盐 scrypt（N=32768、r=8、p=1，64字节输出），不保存明文。Cookie原值、数据库密码、初始密码不写审计。

病例／考试表尚未建立，当前此类授权只记录明确 ID，不证明资源存在，也不开放真实内容。接入业务表时必须添加同机构资源存在性校验，不能直接将用户任填 ID 当作合法资源。画像授权已校验目标是本机构对应角色账号。

## 4. API 合约

通用路径 `/api/accounts/`。所有响应 `Cache-Control: no-store, private`。JSON请求最大16 KiB；每个 POST 检查 Origin。生产 APP_ORIGIN 必须为实际稳定网站源（协议＋域名，无路径）。

| 方法／路径 | 输入 | 身份与输出 |
|---|---|---|
| POST login | username、password | 无会话；返回安全用户字段并设置 Cookie，不返回令牌 JSON |
| GET me | 无 | 会话有效；返回本人身份及本人授权，首次改密前不返回授权 |
| POST password | currentPassword、password | 包括首次改密会话；成功清除全部旧会话，重新登录 |
| POST logout | 空对象 | 清除当前会话及 Cookie，失效会话退出幂等 |
| GET users | 无 | 管理员；本机构账号列表，不返回散列 |
| POST users | action=create/update/reset/grant/revoke及对应字段 | 管理员；机构来自会话，成功返回 ok |
| GET grants | 无 | 管理员；本机构授权元数据 |
| GET audit | 无 | 管理员；最近100条本机构账号审计 |

错误：400输入不正确；401需登录；403角色／初始密码／来源不允许；404不存在或无权；409冲突；413过大；415非JSON；429登录锁定；503数据库未配置／异常。数据库细节不直接回传浏览器。

创建输入：username、displayName、roles、password。更新输入：userId、displayName、roles、active。重置输入：userId、password。授权输入：userId、resourceType、resourceId、permission、purpose。撤权输入：userId、grantId。

## 5. RBAC 与会话生命周期

- 学生只出现学生端与帮助；教师只出现教师端与帮助；管理员出现管理后台与帮助。组合角色显示其并集。
- 隐藏导航不是安全控制；API 独立校验，学生直接请求管理接口仍返回403。
- 管理员创建账号不默认授予教学正文访问权限。画像管理独立授权，不自动形成排行榜或全院可见。
- `mayAccess` 为后续真实内容接口的统一门禁：校验服务端读取的机构、资源ID、归属、结果发布状态；本轮测试这些规则，但没有伪造真实病例／答卷接口。
- 本人未发布结果不可读；老师读取他人答卷须有对应考试管理授权；管理员身份单独不通行。
- 新建账号首次改密；重置后再次强制改密；停用、重置、角色变更、资源授权变化使旧会话失效。
- 禁止管理员停用自己或移除自己的管理员角色；机构级事务锁保护最后一个有效管理员。
- Cookie：生产 `__Host-path_edu_session`、Secure、HttpOnly、SameSite=Lax、Path=/，不设置Domain。开发本机HTTP不用Secure。
- 页面每30秒及窗口聚焦重查会话。接口立即拒绝失效会话；已显示页面不等于能继续调用。退出／过期清理本机演示草稿并卸载页面。
- 原教学组件的演示草稿按账号ID区分，退出清除；不迁移为正式数据。静态合成图片与打包示例属于公开演示资产，不宣称受私有文件授权保护。

## 7. 已知上限与发布阻塞

本地单进程数据库不能验证20人生产并发。每个云函数实例连接池上限3，不等于全站总连接数上限；需按云实例数乘算，并实测连接回收。登录限流当前是账号维度，公网试用前需入口限流抵抗大量不同账号名请求；不信任未核验代理来源的 X-Forwarded-For。

本轮没有MFA、邮件找回、密码泄露字典或自动禁用过期账号；范围是管理员供给的小规模试用。不能因此移除来源校验、会话失效、TLS或审计。

线上必须落实：独立PG及网络／TLS、最小权限数据库用户、迁移初始化、稳定访问源、备份恢复、入口限流、20人并发、成本告警与真实浏览器验收。不得以本地测试替代这些。
