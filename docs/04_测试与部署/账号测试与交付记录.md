## 4. 你可以亲自验收的步骤

1. 打开 http://localhost:3002 ，读取本机 `.local/首次管理员登录.txt` 中账号和当前密码登录。
2. 在“管理后台 → 新建账号”创建一个学生、一个教师，分别设置12位以上含字母数字的不同初始密码。
3. 在无痕窗口登录学生，确认先改密、再重新登录，只出现学生端和帮助；教师同理。
4. 管理员窗口选择该学生“管理 → 重置密码”。回到学生窗口刷新，应返回登录；新临时密码登录应再次要求改密。
5. 管理员将测试教师停用，教师窗口刷新应回登录；停用账号不能登录。启用后可用原密码登录，除非此前已重置。
6. 在“资源授权”给测试教师某个明确病例ID的查看权，填写用途，保存；在授权列表撤销，审计中应同时有创建和撤销记录。当前测试的是授权记录，不是实际病例读取。
7. 在“操作审计”核对建号、改密、重置、授权、撤销、停用记录；不能修改或删除这些记录。
8. 退出管理员，确认账号管理页消失；浏览器返回不应恢复可操作后台，任何再次调用需校验会话。

请只使用虚构账号信息，不填患者资料。学生教学内容仍是公开示例，不能用它验证真实考试成绩或医学能力。
