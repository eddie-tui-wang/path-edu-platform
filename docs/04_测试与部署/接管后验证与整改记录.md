- 问题：浏览器写入失败时的数据保护缺少实测证据。
- 文件：`scripts/verify-storage-failure-browser.mjs`；业务代码暂未修改。
- 方式：独立临时 Chrome 上下文，针对练习草稿、题库指定存储键模拟 QuotaExceededError；恢复写入后重试。

- 实测：脚本退出码 0。练习错误提示、无虚假保存成功、返回／跨模块取消离开、已选答案保留、重试、重新打开恢复通过；题库错误提示、题干保留、继续编辑、重试、保存后禁用按钮通过。
- 环境记录：普通沙箱启动 Chrome 因权限失败；经授权运行后可正常测试。这不是 Playwright 缺失。首次脚本与 Next 隐藏 alert 匹配冲突，已收窄到具体错误信息后重跑通过。
- 边界：本脚本练习为单选；阅卷补测见下节。练习简答、考试草稿与 sessionStorage 清理失败尚未覆盖，不称所有存储路径已验证。独立浏览器测试不增加单元测试计数。
