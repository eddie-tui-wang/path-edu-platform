### 9.2 AI 追问改为 copilot 轨道

- 入口是**舞台工具栏右侧的按钮**，提交前不存在（无可追问的对象）

- 输入框与发送**保持禁用**——服务未接入，不制造可用假象（沿用既有硬规则）

## 12. 视觉目检与门禁修复（2026-09-11 第九轮）

### 12.1 为什么这一轮才做

此前所有界面验收都是**几何与对比度的程序化测量**，没有任何人（也没有任何模型）看过页面——当时的模型不能读图。本轮第一次对 11 个模块做了**真正的视觉目检**。

### 12.2 方法（可复现）

```sh
node .ui-audit/capture.mjs .ui-audit    # 1440x900，teacher 5 模块 + student 6 模块 + 两个阅片详情 = 14 张
```

逐张读图；对可疑处再用 `locator.screenshot()` + `deviceScaleFactor:2` 放大复核，并用 `getComputedStyle`／DOM 取值交叉验证。**不看缩略图下结论**——本轮两次误判都出在缩略图上（见 §12.6）。

### 12.3 环境事件：3002 的 dev server 曾整体卡死

目检开始时 `curl http://localhost:3002/` 悬挂（120s 无响应）。`lsof -nP -iTCP:3002` 显示 node 进程**仍在 LISTEN**、有 ESTABLISHED 连接。**SIGTERM 无效**，`kill -9` 后端口才释放；以受管后台任务重启后 `Ready in 253ms`。

> 给下一位：dev server 卡死**看起来像**「服务没起」或「脚本超时」。判据是 `lsof` 有 LISTEN 但 `curl` 无响应；此时 SIGTERM 会被忽略，必须 `kill -9`。

### 12.4 目检确认**成立**的部分

- 阅片器：工具盘 `平移／缩放／矩形／圆形／点标注／自由笔`，缩放与自由笔**确为禁用**，`100%` 与 `清除标注` 在位；舞台面积明显大于信息栏。
- 作答台：1440px 下三栏（临床资料／舞台／作答）稳定，舞台最宽。
- 页头规范：返回按钮确在内容区左上角且为页头第一个元素（`返回图书馆`、`返回练习列表`）；范围切换（全部切片／我的收藏）在标题行，布局切换（卡片／列表）在结果工具区——符合 DS-03／D-53。
- 示例来源可辨识：「示例」标签出现在教师 教学记录／能力分析 页头与能力分析各维度行，DS-09 的「收敛为一个示例标签」是**真的**。

### 12.5 发现并修复：`.library-tag`「示例」胶囊被拉宽成空壳

**症状**：教师 教学记录／能力分析 页头的「示例」胶囊宽 112px，文字只占 28px，**右侧约 68px 是空白**，缩略图下看起来像一个空标签。

**根因**（实测，非推测）：`app/migrated.css:520`

```css
.teacher-ability > header span:not(.teacher-rule) { display: block; ... }
```

特指度 (0,2,2) 压过 `.library-tag`（0,1,0）：胶囊的 `display` 被算成 `block`，于是**填满标题块宽度**（112px ＝ `<h1>` 的宽度）；同时 `color` 被改成 `--primary`、`font-weight:700`、`letter-spacing:.08em`。

该规则**本就已排除**同类的 `.teacher-rule` 胶囊（第 523 行），只是后来新增的 `.library-tag` 没被排除——**修复沿用既有模式**，不是新发明。

**修复**：选择器补 `:not(.library-tag)`，并单独保留原来的 10px 间距。

**验证**（`getComputedStyle`，修复前 → 修复后）：

| 指标 | 修复前 | 修复后 |
|---|---|---|
| `display` | `block` | `inline-block` |
| 胶囊宽度 | 112px | **44px** |
| 空白 | 68px | **0** |
| 文字颜色 | `#007c57`（`--primary`） | `#005e42`（`--primary-strong`） |
| 对比度 | 4.68:1 | **7.02:1** |

### 12.7 发现（已修）：门禁「假绿」——3 个回归脚本因 `c71f6a3` 过期

**这是本轮最重要的发现。** 交接文档写的「11 个浏览器脚本全部通过」在接手时**不成立**。

`c71f6a3`（列表改高密度表格）把 题库与出题／试卷／学习记录 的逐条 `<article>`+`<h2>` 换成 `.data-table` 的 `<div>`／`<details>`，但**只同步更新了 `verify-detail-browser.mjs`**，另外三个仍按 `locator('article')` 取行：

| 脚本 | 过期选择器 | 现象 |
|---|---|---|
| `verify-annotation-tail-browser.mjs:37` | `article` + `heading` | 题库行已无 `<h2>`，等不到 |
| `verify-storage-failure-browser.mjs:25` | `article` | 题库行不再是 `article` |
| `verify-publishing-browser.mjs:11／37／84` | `article` | 教师试卷行已变 `.data-table > details` |

**证据**：`document.querySelectorAll('article').length` 在 题库与出题 与 考试管理 均为 **0**（`.data-table` 分别为 1 容器／20 行 与 1 容器／3 行）；`git show --stat c71f6a3` 的 13 个受改动文件里只有一个 verify 脚本。

> 这不是代码回归，而是**脚本过期**（skill 反面清单里的典型情形）。学生端 考试中心 仍是 `<article>` 卡片，所以那里同名的选择器**保持不动**。

**修复**：教师端改按行文本定位（`.data-table > div` / `.data-table > details`），并加注释说明为什么两侧写法不同。

**验证**：三个脚本修复后**均 exit 0**。
