# 测试与部署计划 v0.2.0

## 1. 当前状态

本轮仅更新文档，不重跑应用、不更改部署。已有项目与历史测试保留，但下表针对最终方案的用例均待执行；不得沿用上轮通过数当作新功能验收。产品需求见[模块目录](./模块PRD/README.md)。

分三层验证：本机模拟流程（不承诺跨设备共享）；真实服务闭环（须真实接口、存储和授权证据）；医学质量（须专家素材与量表）。第二期WSI另测，不阻塞第一期JPG／PNG文档。结构检查不等于业务测试通过。

## 2. 数据与记录准备

教师A／B、学生A／B、管理员及无权账号；四类素材含空分类、授权／未授权病例、多图；单选／简答已确认题和未确认草稿；全单选、全简答、混合卷，均按模拟考试10片准备。另准备9片、11片及同图重复引用的无效卷。简答仅文本区，不能沿用旧必需标注提交测试。

每次执行记录测试ID、模块及规则ID、环境、应用／数据版本、操作、预期／实际、证据、问题及复测。状态未执行／通过／失败／依赖阻塞。不能记录真实密码、患者身份或完整密钥。

## 3. 可执行测试清单

| Q01 | C-ACCOUNT、C-OPS | 角色入口、账号搜索新增启停重置，尝试访问他人对象 | 入口与权限匹配；真实服务所有路径校验；本地演示明确边界 |
| Q02 | C-ACCOUNT | 顶栏、恢复按钮、管理员列表、窄屏及200%缩放 | 无冗余角色／帮助导航，统一按钮，新建按需展开，关键操作可达 |

| Q04 | T-LIB | 上传有效／损坏JPGPNG、重名、中断；更新被引用图片 | 失败状态可见；发布快照及历史图片不被覆盖 |
| Q05 | T-QUESTION、A-GEN | 选片生成、改选项顺序、删正确项、失败、重生成 | 引用对应病例；答案始终唯一有效；无依据不生成确定答案；人工修改不被悄悄覆盖 |
| Q06 | T-QUESTION | 单选或简答新建、学生预览、确认入库和开放练习 | 无多选；草稿不能被选入发布卷；预览无私有答案；入库不自动开放练习 |
| Q07 | T-PAPER | 从题库选择10片组全单选／全简答／混合；尝试9片、11片、同图重复凑数 | 只合法10独立影像卷可发放，题分总和正确；10片不强制10病例或10题 |
| Q08 | T-PAPER、S-EXAM | 分配A不分配B；修改题库或病例后查看已发卷 | A可见B不可见，未发放学生显示空态；快照不随源资料变化 |
| Q09 | S-PRACTICE | 单选提交前后查看解析与AI，伪造未提交／他题／考试AI请求 | 提交后立即显示教师答案解析；AI仅当前已提交练习开放；失败不遮解析 |
| Q10 | S-PRACTICE、S-EXAM | 简答加粗、列表、撤销重做、切题刷新和提交 | 基本文本格式保留，没有复杂结构表或强制标注；保存正确且仅按文本完成判定 |
| Q11 | S-EXAM | 开始、恢复、修改本机时间、双标签页冲突、断网到时、重复提交 | 不重复创建答卷、不延长考试、不静默覆盖冲突；真实服务拒绝逾期补交，保留本地稿 |
| Q12 | T-GRADE | 单选正确／错误／空答；简答AI失败、人工复核与整场发布 | 确定性分数；失败非0；未完成复核阻止发布，未交卷不伪造零分卷 |
| Q13 | S-RESULT、S-WRONG、S-ABILITY | 练习错误、未发布考试、发布后更正；同题多版本 | 来源分开，未发布考试不泄露，修正同步且不重复统计；区域无证据不补数值 |
| Q14 | T-AUDIO、A-ASR | 上传正常／损坏／超限录音，中断重试，转写校订 | 音频真实保存并可回放；转写带时间，原版保留；不测试或要求站内麦克风采集 |
| Q15 | T-AUDIO | 无互动、术语错误、无参考诊断、无图片事件、单模块失败 | 引用可追溯；无事件不生成轨迹热图；保留其他有效分析，不虚构问答 |
| Q16 | T-ABILITY | 只有录音、只有浏览、实际AI生成修订、资源贡献 | 各维独立不足；不把次数／浏览当能力或建设；有量表才显示分数 |
| Q17 | C-OPS、所有AI | 超时、限流、余额、无效结构、重复任务和恶意输入指令 | 有限重试、状态真实、权限不变，不重复计分或无限消费；密钥不泄露 |
| Q18 | 全模块 | 默认题卷初始化两次、切换师生、重置账号、另设备打开 | 不覆盖用户数据；同机共用卷ID；另设备不谎称共享答卷；仅账号重置不清业务 |
| Q19 | 全模块 | 学生与教师旧界面布局回归、键盘、移动端、刷新返回 | 旧三栏和导航保持，已取消控件不回归，文字和按钮可读 |
| Q20 | 真实服务阶段 | 20人负载、院外手机访问、备份恢复、回退与撤权后旧链接 | 记录实测性能与数据一致性；权限和存储确实生效，旧站不改变 |
| Q21 | 第二期 | WSI解析、瓦片、可靠标定、旧图及答卷回看 | 不替换业务后台；无映射不转旧标注，旧图数据可读 |

三条端到端链路：
1. 教师选片→AI单选草稿→调整确认→开放练习→学生提交→教师解析→AI追问。
2. 教师从题库组10片卷→分配学生→学生按旧界面作答→提交→教师复核发布→学生结果／错题／能力。
3. 教师上传录音→转写校订→教学分析→四维证据／不足状态→点击时间戳回放。

真实服务验收不得用假AI或假上传替代；可用模拟服务验证失败边界，但执行记录必须说明。

## 4. 部署与预算

本轮不执行部署，独立EdgeOne站点与仓库保留，不重复要求创建。当前接受无数据库本地原型；真实院外师生共享需另落实业务存储，不能用localStorage冒充。AI密钥仍需服务端代理与额度控制。ASR未选择，不默认购买或承诺100元预算足够，具体周期及用量进入依赖确认。

开发、测试和实际试用分离数据与凭据；不得使用旧科研平台生产凭据。真实图片／音频存储需私有访问，匿名静态目录仅放授权合成素材。边缘入口、长任务和数据存储分别核验，不默认单个部署服务满足全部需求。

20并发目标保留，配比、时长、P95、AI耗时和文件限额待容量预算确认；未确认先记录实测。医学评测单独由专家确定阈值，不把冒烟当准确率验证。

## 5. 发布、恢复与交付

发布前检查需求对应Q用例、依赖阻塞、接口权限、额度、日志脱敏及素材授权；实际服务未验收不显示真实成功。数据库与对象文件共同备份，恢复在隔离环境验证影像／答卷／音频引用。RPO、RTO、保留期按资源条件确认，不预填保障值。

回退优先应用版本，数据库向后兼容；如恢复备份可能丢数据，须说明时间范围并获准后执行。旧科研站点不在回退范围。交付应用版本、测试记录、AI评测、部署配置说明（无密钥）和恢复报告；本轮仅文档结构与链接检查。
