# 教学原型迁移与两期演进清单 v0.2.0

## 2. 最小数据契约

| 对象 | 必须记录 | 约束 |
|---|---|---|
| 病例／影像 | ID、库与权限、四类目录、病史、图片尺寸类型版本、素材来源 | 公开材料与教师参考分开；题目引用固定版本 |
| 题库题目 | ID、版本、单选／简答、图片、题干、选项ID、参考、解析、评分点、确认人、练习开放范围 | 生成草稿不直接可用；只单选，无多选；开放练习不自动发卷 |
| 试卷及分配 | ID、版本、题目快照、10个独立影像、题分、时长、窗口、目标学生 | 题目可复用，已发卷不可覆盖；10片不固定10病例 |
| 作答 | 场景practice／exam、学生、题或卷版本、单选项或文本格式、保存修订、提交时间 | 共用查看能力但门禁分开；考试提交唯一，原答不可改 |
| 评分／结果 | 程序得分、AI建议、教师复核、理由、发布版本 | AI不改单选；练习和考试分开；更正更新错题画像 |
| 音频及转写 | 文件ID版本、教师、授权、时长、可选病例、转写与校订、时间片 | 原版保留；无图片事件不记录假视野 |
| 分析 | 输入版本、模型／规则版本、任务状态、引用、用量 | 幂等；任务完成与教师确认／发布是不同状态 |

简答首期仅文本输入；原标注若保留使用原图坐标和影像版本，不作为必需答案。以题干主题不能替代真实区域能力证据。

## 3. 两期边界

第一期JPG／PNG、共用病例及题库、练习与考试、文本生成分析、上传录音目标；当前本地原型仍可先验证UI，真实服务验收必须另有调用和存储证据。第二期新增WSI大文件、解析、瓦片和标定，不替换业务后台；无可靠对应不将旧图及标注覆盖成WSI。

原浏览器记录不自动变正式业务数据。种子初始化不覆盖已有题卷答卷，旧示例需标记停用或独立版本；任何清理必须明确对象范围。跨设备共享须实际服务端存储，不能靠相同种子ID假装同步提交。
