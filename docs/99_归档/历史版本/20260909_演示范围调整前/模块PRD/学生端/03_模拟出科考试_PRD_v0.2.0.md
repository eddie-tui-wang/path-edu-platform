# 学生端｜模拟出科考试 PRD v0.2.0

## 1. 产品定义

- **这是什么功能：** 查看教师发放的10张切片模拟试卷，阅片作答并提交考试。
- **帮助用户解决什么问题：** 让学生明确何时有考试、如何完成，以及何时查看成绩。
- **为平台带来什么价值：** 形成独立于练习的考试证据和能力输入。

> **实施前置依赖：** 10张图片、发放关系与真实跨设备保存D-F01、D-F05；医学评分D-F02。 统一见[实施依赖清单](../../实施依赖与待确认清单.md)。已确认产品行为不等于服务已接通或医学效果已验证。

## 2. 产品结构

考试列表 → 已分配试卷说明 → 开始 → 按题阅片作答 → 整卷提交 → 等待发布。

共用阶段、数据版本与权限原则见[需求总纲](../../独立病理教学网站MVP需求稿_v0.1.0.md)，模块入口见[目录](../README.md)。

## 3. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| S-EXAM-01 | 查看教师发卷 | 待参加／进行中／已提交列表 | 只列教师发放且分配给本人的卷；没有则暂无考试，不自动生成随机十片卷。显示10张切片、实际题数、题型、总分、时长和时间窗口。 |
| S-EXAM-02 | 确认开始 | 说明、开始确认和题片目录 | 开始创建唯一答卷并固定试卷及病例版本；一场一次机会，截止取关闭时间与个人时限较早者。恢复不重新计时。 |
| S-EXAM-03 | 阅片阅读病史 | 旧三栏：左病例、中图片、右答案 | 原旧学生PRD第10节为迁移基准，保留布局与导航。按题目关联显示图片与病史，第一期JPG／PNG，不虚构WSI倍率。 |
| S-EXAM-04 | 按题作答 | 单选选项或基本文本框 | 单选只能选一个；简答在单一文本区表达诊断、鉴别、IHC，可使用加粗／列表／撤销重做。原复杂疾病字段和强制标注不作为第一期提交条件。 |
| S-EXAM-05 | 切题与恢复 | 底部题目目录、剩余时间和保存反馈 | 自动保存文本、选项、当前题和阅片位置。切换到不同病例必须更新图片；刷新恢复已保存数据，失败不显示已同步云端。 |
| S-EXAM-06 | 检查并提交 | 整卷完成概览、空题提示和确认 | 10张切片可关联不同数量题目。允许确认后带空题提交，空答按规则计0；提交锁定整卷，重复点击不产生多份答卷，超时按总纲处理。 |
| S-EXAM-07 | 等待教师发布 | 已提交／待复核／待发布状态 | 考试作答期间关闭AI、参考答案和解析；交卷后也不自动开放练习AI。教师发布后才能查看本人结果，考试不新增AI对话入口。 |

## 4. 专项规则与数据关系

模拟卷由教师发放，学生不能自行开始未分配卷；10片不被解释成固定10病例。全单选、全简答或混合由试卷决定。考试和练习使用共用阅片框架但不同提交与答案开放规则。第一期简答不采强制区域证据，区域能力无数据不得给分。

所有保存反馈必须对应实际写入结果；本机保存不显示已同步云端。修改被引用内容建立新版本，历史记录使用当次快照。未落实医学规则不由开发者或模型自行定为标准。

## 5. 权限与状态

仅本人分配与答卷；试卷时间状态与个人作答状态分开。进行中可恢复，已提交不可改；离线过期不得靠修改本机时间延长，保留本地稿并显示提交未被接受。

真实服务接入时同时校验入口、列表、检索、详情、文件和写入；浏览器演示不能声称具备真实隔离。

## 6. 界面框架

左临床、中阅片、右单选／文本；底部病例题目导航、计时、检查和提交。无改版式创新，不恢复旧稿与最新单选／文本简化冲突的控件。

沿用六院绿色Design System与旧平台相关组件；截图示意说明是页面设计要求，不是本轮已完成截图。参考学生旧稿[第10节界面框架](../../../03_Agent方案/切入点需求稿/07_切片图书馆病例模拟作答/学生病理教学模块需求稿_v0.3.1.md#10-界面框架)，仅继承适用布局，不恢复已取消的多选、复杂简答表格及强制标注规则。
