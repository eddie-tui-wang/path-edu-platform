# 默认练习与10片模拟卷设计

版本v0.2.0／P0，2026-09-09。仅数据规格，尚未初始化到师生界面。旧6题100分示例含多选和强制标注，已退出当前基线，旧定义在历史快照保留。

## 1. 共用与初始化

默认教师demo_teacher、默认学生demo_student；一个共同题库和试卷ID，教师可查看和复制草稿，学生只见已开放练习与已发放考试。首次初始化缺少ID才写入，刷新不覆盖用户编辑、答卷和成绩；修改用新版本，旧答卷仍引用旧版。新建学生不自动获得全部考试。

同浏览器可验证两角色共享题卷；不同设备最多初始化相同题目，不能因此共享学生提交或教师评分，真实共享依赖D-F05。不得预置个人已考成绩、错题或画像。

## 2. 单选练习样例

ID：DEMO-PRACTICE-001，版本2。题型single。关联模拟材料卡：取材方式为活检、取材部位为“教学部位A”，病程未提供，诊断未确认，图为授权合成素材。

题干：当前材料中哪项已经明确？

- A：确诊结论。
- B：取材方式为活检。
- C：完整病程长度。
- D：免疫组化结果。

教师确认参考答案B；预设解析：“材料明确给出活检，其余信息未提供，不能自行补全。”此为软件流程演示，不是病理诊断题。提交前不显示参考与AI，提交后直接展示教师解析，AI可依据同一卡片解释信息缺失。AI服务未接不能显示真实生成成功。

该条是供种子初始化的已确认样例，不等于验证AI自动出题；另需Q05测试真正选片生成、修改、确认全流程。

每题统一学生题干模板：“阅读本题图片和病史，以文字描述主要观察、最可能诊断或不确定性、需要考虑的鉴别方向，以及必要时拟补充的免疫组化与目的。”使用一个基本文本区，不能要求填写多个结构化表格或强制标注。

病例病史与医学参考须由教师逐题匹配填写。软件演示可明确采用虚构信息及D1／D2、M1／M2标签；这些只测试字段和流程，不作为正式医学答案。正式参考未齐时题目保留草稿，不为了演示发放伪装为已确认；确认人不可预填真实医生名字。具体素材及评分点见D-F01、D-F02。

10题是此样卷示例，不是产品规则；正式组卷允许一片多题或一病例多图，但整卷必须10个真实独立影像版本。

## 4. 需验证的联动

教师看到题库及已发卷，学生看到同ID和版本；简答文本和格式刷新恢复；考试无AI／无提前答案；教师阅卷发布后学生结果、错题、能力一致；再次初始化不覆盖；没有专业参考不输出真实医学分数。初始未提交状态应为空记录，不生成已考画像。Q05—Q13、Q18对应检查均待执行。
