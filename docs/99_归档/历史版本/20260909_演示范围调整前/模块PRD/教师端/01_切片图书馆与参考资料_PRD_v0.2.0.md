# 教师端｜切片图书馆与参考资料 PRD v0.2.0

## 1. 产品定义

- **这是什么功能：** 检索、阅片并维护出题所需的病例、切片和已确认参考资料。
- **帮助用户解决什么问题：** 减少教师在选片、找病史和准备参考答案之间的反复切换。
- **为平台带来什么价值：** 为题库、练习、考试及教学分析提供共同的版本化资料源。

> **实施前置依赖：** 素材授权、病例字段和专家确认资料缺失时，保留检索与草稿，阻止无依据AI出题；见D-F01、D-F02。 统一见[实施依赖清单](../../实施依赖与待确认清单.md)。已确认产品行为不等于服务已接通或医学效果已验证。

## 2. 产品结构

全部切片／我的收藏 → 分类检索 → 病例详情与阅片 → 参考资料 → 用于出题。

共用阶段、数据版本与权限原则见[需求总纲](../../独立病理教学网站MVP需求稿_v0.1.0.md)，模块入口见[目录](../README.md)。

## 3. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| T-LIB-01 | 浏览与筛选 | 分类条、来源筛选、搜索及双视图 | 沿用旧切片图书馆的分类、检索、收藏、卡片／列表与详情体验。来源区分标准库、院方库；计数从当前可见数据计算。 |
| T-LIB-02 | 选择病例阅片 | 病例信息、多图缩略图、主阅片区 | 打开所选病例和影像版本，平移缩放、切换图片；返回保留搜索、分类、视图和滚动位置，不把所有卡片指向同一示例图。 |
| T-LIB-03 | 维护临床资料 | 基础信息、病史、送检及检查分组 | 授权教师维护院方病例及JPG／PNG素材，填写来源与使用权限。缺失字段保持未提供，不生成虚构病史。标准库修改需单独授权。 |
| T-LIB-04 | 维护参考依据 | 教师私有诊断、鉴别、IHC与来源区 | 为出题准备已确认诊断、形态描述和资料片段；标注确认人、时间和版本。学生公开材料与教师参考字段分开。 |
| T-LIB-05 | 选片进入出题 | 用于出题按钮及关联材料摘要 | 将病例ID、所选图片版本及关联文本交给题库编辑器；老师选择片子是出题起点，不能只传图片文件名而丢失病例依据。 |
| T-LIB-06 | 管理收藏与版本 | 收藏状态、保存状态和引用提示 | 收藏按账号保存；资料修改形成新版本，不覆盖已发布题目、试卷和历史答卷。已被引用图片保留历史访问。 |

## 4. 专项规则与数据关系

分类顺序固定：骨与软组织肿瘤／肉瘤 → 甲状腺肿瘤／甲状腺癌 → 前列腺癌／泌尿系统肿瘤 → 妇科肿瘤。此为用户指定教学目录，不自动推断医院排名或医学优势。迁移相关资料库能力，不带科研项目、GPU或训练业务。第一期图片只显示相对缩放。

所有保存反馈必须对应实际写入结果；本机保存不显示已同步云端。修改被引用内容建立新版本，历史记录使用当次快照。未落实医学规则不由开发者或模型自行定为标准。

## 5. 权限与状态

教师只维护本人或明确授权资料；学生只读开放字段。上传中／可用／失败，资料草稿／已确认按对象独立显示；未确认资料不能作为AI确定答案依据。

真实服务接入时同时校验入口、列表、检索、详情、文件和写入；浏览器演示不能声称具备真实隔离。

## 6. 界面框架

顶部标题与新增入口；下方分类和搜索；主体卡片／列表。详情左临床、中阅片、右教师参考或操作；不另叠科研平台导航。

沿用六院绿色Design System与旧平台相关组件；截图示意说明是页面设计要求，不是本轮已完成截图。参考学生旧稿[第10节界面框架](../../../03_Agent方案/切入点需求稿/07_切片图书馆病例模拟作答/学生病理教学模块需求稿_v0.3.1.md#10-界面框架)，仅继承适用布局，不恢复已取消的多选、复杂简答表格及强制标注规则。
