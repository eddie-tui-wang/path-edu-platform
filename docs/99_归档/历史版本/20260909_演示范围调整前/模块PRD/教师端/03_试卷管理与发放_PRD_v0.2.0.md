# 教师端｜试卷管理与发放 PRD v0.2.0

## 1. 产品定义

- **这是什么功能：** 从题库选择已确认题目，组卷、预览并向学生发放模拟考试。
- **帮助用户解决什么问题：** 避免教师每次考试重复编题，也让学生明确能参加哪些考试。
- **为平台带来什么价值：** 形成题库到试卷快照及分配关系的稳定链路。

> **实施前置依赖：** 目标学生名单、10张授权素材与实际文件版本需落实；模拟卷可用种子验证流程，不能伪造已有学生答卷。D-F01、D-F05。 统一见[实施依赖清单](../../实施依赖与待确认清单.md)。已确认产品行为不等于服务已接通或医学效果已验证。

## 2. 产品结构

试卷列表 → 新建 → 题库选题 → 排序与配置 → 预览 → 发放 → 查看提交状态。

共用阶段、数据版本与权限原则见[需求总纲](../../独立病理教学网站MVP需求稿_v0.1.0.md)，模块入口见[目录](../README.md)。

## 3. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| T-PAPER-01 | 新建试卷 | 草稿／已发放／已结束列表与新建按钮 | 填写名称，选择全单选、全简答或单选＋简答混合。模拟出科考试使用10张切片，由教师组织并发放，不提供学生自建模拟卷。 |
| T-PAPER-02 | 从题库挑题 | 题库选择器与已选题清单 | 仅选择已确认且有权限的题目版本；可按四类部位、题型筛选。显示每题病例及图片，不能在此绕过题库确认直接发布新题。 |
| T-PAPER-03 | 整理顺序与分值 | 可排序题卡、题数／片数／总分汇总 | 调整顺序和题分；汇总独立影像ID＋版本的数量。同一张图被多题引用仍算一张，10张不等于10题或10病例；重复引用不凑片数。 |
| T-PAPER-04 | 配置发放 | 学生选择、时长及开放关闭时间 | 指定当前有效学生与考试时长、窗口。未分配学生不能开始；没有发放卷的学生显示暂无考试。日常练习开放不能替代考试分配。 |
| T-PAPER-05 | 学生预览与检查 | 完整阅片答题预览、发布问题列表 | 检查10张片子、题型构成、图片可读、评分齐全、学生有效及时间合理；若题目已经开放练习，提示试题曾曝光，由教师决定是否继续使用。 |
| T-PAPER-06 | 确认发放 | 发放摘要、目标学生和版本号 | 冻结题目、选项、临床信息、影像、参考、评分点及规则；两端读取同一试卷ID和版本。发放成功后学生列表可见。 |
| T-PAPER-07 | 管理已发放试卷 | 提交状态、只读配置与进入阅卷 | 发放后不直接改题；需修改复制新版本并重新发放。未开始考试可取消，存在答卷保留记录；截止后不新增开始机会。 |

## 4. 专项规则与数据关系

模拟考试10张切片是整卷发布校验，不强制每个病例恰好1张，也不强制每片只1题。全单选、全简答、混合卷继续支持，但第一期无多选。试卷得分为各题得分之和，不额外叠加隐藏题型权重。已确认题目修改不回写已发放快照。

所有保存反馈必须对应实际写入结果；本机保存不显示已同步云端。修改被引用内容建立新版本，历史记录使用当次快照。未落实医学规则不由开发者或模型自行定为标准。

## 5. 权限与状态

教师仅自有／授权试卷和学生范围；学生仅本人分配。试卷草稿／已发放／已取消，时间窗口决定未开放／开放中／已结束；个人作答状态另记，不混成一个状态。

真实服务接入时同时校验入口、列表、检索、详情、文件和写入；浏览器演示不能声称具备真实隔离。

## 6. 界面框架

列表优先；组卷页左题库筛选，中已选题顺序与题分，右试卷摘要；发放单独确认页，不把出题、选题、阅卷都堆在同一长表单。

沿用六院绿色Design System与旧平台相关组件；截图示意说明是页面设计要求，不是本轮已完成截图。参考学生旧稿[第10节界面框架](../../../03_Agent方案/切入点需求稿/07_切片图书馆病例模拟作答/学生病理教学模块需求稿_v0.3.1.md#10-界面框架)，仅继承适用布局，不恢复已取消的多选、复杂简答表格及强制标注规则。
