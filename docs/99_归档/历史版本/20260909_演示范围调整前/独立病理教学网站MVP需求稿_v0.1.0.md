# 独立病理教学网站需求总纲 v0.4.0

## 1. 产品定义

- **这是什么功能：** 面向六院教师和学生的独立教学网站，教师选片出题、题库组卷发放、阅卷及上传教学录音分析，学生查片、练习及参加模拟考试。
- **帮助用户解决什么问题：** 把教学资料、题目、练习、考试与反馈串成一致流程，降低重复准备和跨页面操作成本。
- **为平台带来什么价值：** 形成可复用题库、可追溯答卷与教学证据，支持后续真实服务和WSI演进。

> **实施前置依赖：** 素材授权、医学参考、评分量表、DeepSeek实际调用、语音转写、跨设备数据共享分别落实。具体事项在[依赖清单](./实施依赖与待确认清单.md)，不以文档更新代表功能已经实现。

## 2. 产品结构

教师：切片图书馆与参考资料 → 题库与出题 → 试卷管理与发放 → 阅卷与成绩发布；另有录音上传与教学分析、能力画像与发展建议。

学生：切片图书馆 → 日常练习；模拟出科考试单独入口；我的学习包含记录与结果、错题集、能力分析。

公共：账号与页面框架、授权与分析任务。具体需求以[14个模块PRD](./模块PRD/README.md)为唯一详细维护位置，总纲只维护共同规则。

## 3. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| G01 | 选片准备 | 四类图书馆、临床资料与参考区 | 四类固定排序，共用标准库／院方库，按角色开放内容；教师从所选片子进入出题。 |
| G02 | 出题入库 | 问卷式题卡、生成、调整与预览 | 第一期仅单选和简答；单选AI依据关联文本生成，教师调整确认入库。简答由教师维护题干与参考，学生用基本文本区。 |
| G03 | 练习开放 | 已开放题目列表、提交后解析与AI | 教师确认题目后明确开放练习；单选提交即看教师预设答案解析，AI仅在练习提交后开放。 |
| G04 | 组卷发放 | 题库选择、10片计数、学生分配 | 教师从题库组卷，模拟出科考试整卷10张切片，指定学生发放；学生不自行生成卷。 |
| G05 | 考试阅卷 | 旧三栏作答、整卷提交及教师复核 | 学生完成单选或文本简答；考试关闭AI与答案。教师复核并整场发布后开放考试结果。 |
| G06 | 录音分析 | 文件上传、转写、证据及多维结论 | 上传教师讲课录音，分析互动、诊断及讲解过程；缺少图片事件不伪造图像轨迹。 |
| G07 | 学习与发展 | 记录、错题、师生维度证据 | 练习和考试分开；教师四维与学生五维均按有效证据展示，未覆盖不补分。 |

## 4. 五层共同设计

| 层次 | 当前规则 |
|---|---|
| 战略层 | 独立六院教学网站，先完成可体验流程；不扩展收费、多机构合作、课程、证书与排名。20人并发仍是待执行容量目标，不是本轮验证结果。 |
| 范围层 | 以用户最终流程及14模块为边界。第一期JPG／PNG；不增加自动病理图像诊断、WSI解析或通用问卷全部功能。 |
| 结构层 | 题库独立于试卷，练习独立于考试，录音教学分析独立于批卷；同一病例／题目／影像使用版本关联。 |
| 框架层 | 顶部仅品牌和账号操作，侧栏导航；旧学生PRD第10节左病史、中阅片、右作答及底部导航为基准，不重设计版式。 |
| 表现层 | 六院绿色Design System，统一按钮／表单；正文16px、辅助14px，窄屏重排及200%缩放。删除重复解释横幅，保留必要告知与简短示例标签。 |

旧界面“原样迁移”指布局、主要控件和操作习惯，不恢复已被最新要求替换的多选、真实倍率、复杂简答结构或强制标注。

## 5. 共同题型、材料和数据规则

1. 第一期选择题仅单选：至少两个非空选项，恰好一个正确选项；学生只能选一个。题卡可增加、删除、重排选项，答案绑定选项ID。不是完整问卷产品复制。
2. 简答为一个文本编辑区，基本工具限加粗、列表、撤销／重做。题干可要求诊断、鉴别和免疫组化思路，但不拆成强制字段。基本阅片标注可保留，不作为首期完成／评分必需项。
3. 试卷可全单选、全简答或混合。模拟出科考试为10个不同影像ID＋版本；重复引用同一图不凑数量。10片不强制等于10病例或10题。
4. 图书馆分类顺序：骨与软组织肿瘤／肉瘤 → 甲状腺肿瘤／甲状腺癌 → 前列腺癌／泌尿系统肿瘤 → 妇科肿瘤。无资料分类显示空态，不复制同图伪造覆盖。
5. AI单选生成输入是教师选片关联的病史、确认诊断、形态描述和知识片段。缺依据不生成确定答案。AI草稿经教师确认后才可用；生成不直接公开。
6. 题目确认、练习开放、组卷发放、成绩发布是四个独立动作。入库不自动给学生看答案；题库更新不修改已发卷和历史作答。
7. 冻结病例、图片、题目、选项顺序、参考、评分及能力映射版本。练习记录绑定题目版本，考试答卷绑定试卷快照。学生原答与AI输出、教师点评分别保存。
8. 单选按正确项确定性计分，AI不改分；简答按教师确认得分点评分，整卷题分相加，无额外隐藏权重。空答0分；调用失败和依据不足不是0分。

## 6. 场景、权限与状态

| 场景 | 答案与AI开放 | 结果与权限 |
|---|---|---|
| 日常练习 | 本题提交后显示教师确认答案解析，再开放当前题AI对话 | 只限本人已开放练习；AI不读取其他未提交题答案。简答AI反馈与正式考试成绩分开。 |
| 模拟考试 | 作答期间无答案无AI；交卷后等待教师发布，考试不新增对话入口 | 仅教师已发放且分配给本人的考试。每场一次答卷，发布后可看本人成绩及允许的参考。 |
| 教师出题 | 可见授权参考，AI生成需教师确认 | 教师只管理本人／明确授权资源；标准库写入单独授权。 |
| 教师录音／画像 | 原音频、转写与结论仅本人或明确授权 | 录音证据不自动补齐AI应用／资源建设维度，不默认给管理员医学内容权。 |

账号启用／停用／待改密；题目草稿／生成中／失败／待确认／已确认／已停用；试卷草稿／已发放／取消，另计算开放时间状态；答卷未开始／进行中／已提交；评分待处理／已复核，结果待发布／已发布；分析等待／运行／完成／部分失败／失败／依据不足。

真实服务须覆盖入口、列表、搜索、详情、文件、生成、评分和写入授权，不能信任浏览器角色和已提交标记。管理员处理账号及任务不自动获得改分权。

考试开始锁定唯一答卷，截止为个人时限与关闭时间较早者；刷新不延长。自动保存显示实际成功，冲突不静默覆盖。整卷可确认空题提交并锁定；重复提交幂等。真实服务以服务器时间与已接收版本为准，断网过期保留本地稿并说明未被接受，不静默补交。

教师完成所有已提交需处理答卷后整场发布；未交卷不伪造为已提交零分卷。更正结果须原因、新版本和历史记录，错题与能力按同一发布版本更新。练习和考试默认分别统计；缺区域证据不补五维分数。

## 7. 阶段与工程边界

当前授权仅修改文档。现有独立项目及部署保留，不创建新仓库、不购置资源、不推送。本地原型方案仍有效：本浏览器保存不等于云端共享或真实隔离。新增AI生成、录音上传分析是目标能力，未接通必须明确状态，不能以假成功验收；ASR服务待落实。

第一期图片资源记录ID、类型、尺寸、版本与能力；标注若使用，绑定原图坐标；任务保存输入版本与证据。第二期新增WSI解析、瓦片与标定，复用账号、题库、试卷、答卷；历史图不能直接覆盖成WSI，无可靠映射不转旧标注。
