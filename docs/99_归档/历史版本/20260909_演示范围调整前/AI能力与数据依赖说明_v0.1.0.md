# AI能力与数据依赖说明 v0.2.0

配套[总纲](./独立病理教学网站MVP需求稿_v0.1.0.md)及[模块PRD](./模块PRD/README.md)。这是技术依赖说明，不是新增并行产品PRD。当前只改文档，DeepSeek已开通不代表对应业务已接通；ASR待落实，不沿用旧“全部转写延期UI”的目标范围。

## 1. 服务分工

DeepSeek处理文本生成与分析；ASR处理上传录音转写；程序处理单选计分、权限、计时、状态、指标汇总；教师确认医学参考、题目和最终考试评分。选片传递病例及影像版本，文本模型使用关联病史、诊断和资料，不默认识别图片或自动诊断。第一期不依赖Hugging Face病理模型，不查询或猜测未验证的当前模型视觉能力。

## 2. 能力与输入输出

| 编号／模块 | 能力／输入与依据 | 输出与人工确认 | 失败行为与验证 |
|---|---|---|---|
| A-GEN／T-QUESTION | 单选生成：所选病例病史、确认诊断、形态描述、资料片段及题目要求 | 题干、至少2选项、唯一正确项、解析、来源ID；教师调整并确认入库 | 缺依据阻止确定答案，失败留草稿；验证选项ID、答案唯一、引用支持、教师修改不被覆盖 |
| A-PRA／S-PRACTICE | 提交后练习对话：本题已提交答案、教师解析、允许的病例资料 | 解释与追问回答、引用、局限；不更改预设答案或得分 | 服务端验证练习场景及提交；调用失败保留教师解析；测试未提交／他题／考试请求不获答案 |
| A-SHORT／T-GRADE、S-PRACTICE | 简答文本分析：原文、教师参考、逐点评分规则及病例资料 | 命中、遗漏、无法确认、证据引用；考试建议分交教师复核，练习反馈不作为正式成绩 | 越界分数、无来源、无效结构不入有效结果；合理但参考未涵盖交教师判断；空答与调用失败分开 |
| A-ASR／T-AUDIO | 实际上传音频、文件版本、可用术语表 | 时间段、转写及不清晰标记，教师可校订并保留原版 | 损坏／超限／听不清真实提示；不得补造问答；测试时间戳与原音频对齐 |
| A-QA／T-AUDIO | 已校订转写及上下文 | 问答片段与教学策略解释，引用时间戳 | 无问答显示不足，不用次数替代质量；角色不明不推定身份 |
| A-DIAG／T-AUDIO | 讲解判断与授权的已确认病例参考 | 一致与差异、合理修正及证据局限 | 无参考不判医学正误；测试讲解改口不直接算错误 |
| A-TRACE／T-AUDIO | 音频主题时序；只有额外真实阅片事件时才分析图像轨迹 | 讲解顺序及引用；有事件才输出对应视野 | 音频不能反推坐标或热图；无事件图像轨迹显示缺数据而非空动画 |
| A-STUDENT／S-ABILITY | 分来源有效作答、已发布考试、维度映射、错误及样本量 | 程序统计，模型有据解释与建议 | 练习与考试不混算；纯文本无区域证据时不补分；跨卷不可比不画虚假趋势 |
| A-TEACHER／T-ABILITY | 有效录音分析、实际AI出题修订、真实资源贡献 | 四维证据及可行动建议，具体数值依赖专家量表 | 仅音频不能补齐AI应用与资源建设；只浏览不算贡献，无量表显示规则待确认 |

单选评分及教师预设解析不需要AI才能显示。图片几何如需处理用程序；当前简答不强制标注，不将几何比较列为首期评分必需能力。简答AI自动出题、通用教师聊天、互联网自动检索不属于此次新增链路。

## 3. 依据与版本契约

每个有效医学题目关联素材授权、病史、教师确认参考、评分点、来源、确认人及版本。参考引用包含实际来源编号、可定位片段和版本，不编造页码。题目、答卷、转写均为待处理数据，其中指令不能改变权限、评分或调用范围。

任务记录对象ID、场景、输入版本、实际模型／提示版本、状态、用量和引用；重试去重，重分析产生新版本。AI输出、教师修订、最终发布和学生原文分开保存。生成模型不能跳过教师确认，评分模型不能自动发布考试成绩。

练习答案接口与考试答案接口分别校验；练习已提交仅开放本题授权资料，不开放整库，也不把教师私有音频提供学生。

## 4. 数据等级与验证

模拟病史及标签只验证流程；有使用权且经教师确认的图片参考可做限定样本医学评价；WSI上线不自动证明图像诊断有效。四维／五维最低样本、权重、错误标签、难度可比性需专家确认。

每能力覆盖正常、依据不足、服务失败；生成覆盖错误选项、多个正确答案、无支持引用及人工修改；简答覆盖正确、部分正确、错误、同义表达、合理但标准外；音频覆盖术语错、无问答、无参考、无图片事件。评测记录引用有效性、分数偏差、重复波动、费用和耗时，医学阈值由专家确认，不填未经验证的准确率。

## 5. 服务依赖与安全

调用在服务端保管密钥，按任务发送最少必要授权资料；文本模型不默认接收图片或音频，音频仅送获准ASR。配置大小、时长、超时、有限重试和额度，失败不能无限重试消费。真实服务尚未落实时显示未配置或示例，不能声称已完成真实分析。

API已开通、现有EdgeOne项目和不买数据库的阶段决定保留；上传音频需要真实处理能力，不等于已授权购买ASR。方案、预算与数据共享见[依赖清单](./实施依赖与待确认清单.md)，验证见[测试计划](./测试与部署计划_v0.1.0.md)。
