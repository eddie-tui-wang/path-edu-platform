## 版本规则

- 采用语义化版本：`v主版本.次版本.修订版本`。
- 产品边界或教学责任发生重大变化时升级主版本。
- 新增或删除教学场景、典型任务和关键流程时升级次版本。
- 不改变产品决策的文字、链接和细节修正升级修订版本。
- 新版本不覆盖旧文件；由本 README 指向当前版本。
