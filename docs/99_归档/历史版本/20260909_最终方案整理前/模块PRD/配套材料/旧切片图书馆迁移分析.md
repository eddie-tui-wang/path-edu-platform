# 旧切片图书馆迁移分析

版本：v0.1.0｜P0｜2026-09-09｜文档分析，未执行代码迁移

## 结论

采纳“将旧切片图书馆教学相关功能完整迁移”的方向。不是只搬当前病例卡片，但也不是复制整个科研平台。教师与学生共用病理资料入口和资源模型，以权限决定编辑与参考答案可见性。

源代码：../../02_病理科研平台/pathology-research-prototype/app/pathology-platform.tsx 的 SlideLibraryScreen（本次核对约1856行）。该组件在本地生成12条资料，全部复用synthetic-pathology-slide.png；部位200、总量1201等为固定数字；详情仅通知、分页仅文本、打开阅片回调未携带所选影像ID。因此“完整迁移”必须包括这些占位行为的重建，而不是原样复制。

## 逐项迁移对照

| 旧库能力与现状 | 新平台处理 | 教师／学生规则及验证 |
|---|---|---|
| 全部切片／我的收藏切换可交互 | 保留为资料内标签，不再套第二层大型侧栏 | 两角色均可收藏；按当前账号持久化，刷新保留 |
| 器官分类，计数硬编码 | 保留部位分类，计数改为授权数据统计 | 切换类别结果和数量一致，空分类有空态 |
| 医院数据库／公有数据库来源 | 对齐院方库／标准库；保留来源字段，不仅改文字 | 教师院方库可维护，标准库需专门授权；学生只读 |
| 切片号／部位／诊断搜索可交互 | 保留组合搜索，应用访问范围和答案可见性 | 未公开诊断不参与学生搜索与摘要，避免检索泄题 |
| 卡片／列表切换可交互 | 保留，两种视图共用筛选结果 | 切换不重置收藏、筛选及排序；图片对应实际影像 |
| 卡片反复用同一合成图裁剪 | 改为真实资源ID、缩略图、尺寸与版本 | 示例只作为种子，不能冒充12张不同病理影像 |
| 列表详情只弹通知 | 重建病例详情与多图信息面板 | 展示临床资料、来源、图片；教师多参考资料区，学生字段受控 |
| 阅片回调无对象参数 | 重建按病例ID／影像ID／版本打开 | 点击不同影像显示对应资源；返回保留列表上下文 |
| 页码1、2、3…为静态文本 | 按数据量实现分页，小数据仅一页 | 当前页、总量、上一页下一页真实可用，不制造31页 |
| 收藏仅组件状态 | 改为账号维度持久化 | 切换账号不串收藏，资源授权取消后不从收藏绕过 |
| 旧阅片器混有科研上下文 | 只复用图片查看、缩放、标注和适用DS组件 | 不迁移GPU、训练任务或科研项目导航；不启用伪WSI倍率 |
| 新站已有病例编辑／临床信息／组卷引用 | 保留并合并，不用旧库覆盖掉 | 一个病例存储源供资料、考试、记录使用；旧考试保持快照 |

## 目标信息层级

病理资料页面：标题与教师新增入口 → 来源／收藏切换 → 部位与搜索 → 卡片或列表 → 分页。

病例详情：基础信息与临床病史 → 多图浏览 → 资料来源；教师额外显示参考资料编辑和“用于出题／教学记录”。阅片为独立工作区，返回详情或检索结果时保留上下文，不叠加科研平台全局导航。

管理员账号页的列表优先、按需新建，及顶栏去重规则统一见公共模块，不将管理员页面混入教师资料功能。

## 兼容与分期

第一期图像为JPG／PNG，平移缩放、区域标注均按原图坐标；病例下挂多个影像版本。第二期扩展WSI能力、解析和瓦片接口，账号与试卷继续复用。无可靠映射不把历史图片标注迁移到WSI。原型上传限制不等于WSI上传能力。

实施前置依赖：现有素材授权及实际多图资源、可开放的诊断字段、旧库是否存在其他独立页面或后端服务。现有源代码能证明前端行为，不能证明旧平台已有可迁移的服务端数据；补充材料集中在D10，不阻塞本次文档拆分。
