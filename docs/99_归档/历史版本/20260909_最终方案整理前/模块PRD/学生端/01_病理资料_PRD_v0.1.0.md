# 学生端｜病理资料

## 1. 产品定义

- **这是什么功能：** 按授权浏览标准库、院方库中的病例、图片和临床资料。
- **帮助用户解决什么问题：** 在同一个入口查找病例并保留阅片上下文。
- **为平台带来什么价值：** 复用教师维护的病例资产，避免学生端重复建库。

承接旧总稿 F07、F09；共用权限、阶段与数据版本规则见[总纲](../../独立病理教学网站MVP需求稿_v0.1.0.md)。本稿为目标产品规则，非实现完成声明。

## 2. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| S-LIB-01 | 进入资料库 | 资料页标题、来源标签和检索栏 | 从侧栏病理资料进入；展示标准库／院方库及全部资料／我的收藏。学生只读，不提供上传、修改参考答案或资源授权。 |
| S-LIB-02 | 检索与切换视图 | 部位筛选、搜索、卡片／列表、空结果 | 按授权可见数据统计数量；支持病例号、部位及已开放诊断检索，组合来源与部位筛选。卡片／列表保持同一筛选和结果；清空筛选与无权限状态分开。 |
| S-LIB-03 | 查看病例 | 临床信息、图片列表、来源 | 展示教学病例号、临床病史、补充检查、图片及开放的资料；患者直接身份信息不进入教学展示。返回保留筛选、滚动和视图。 |
| S-LIB-04 | 阅片与收藏 | 多图切换、平移缩放、收藏反馈 | 打开所选影像而非统一示例图；显示图片编号与相对缩放。收藏按当前账号保存，刷新后保留；不把教师参考区域变成学生作答标注。 |
| S-LIB-05 | 考试场景隔离 | 试卷内只读病例面板 | 考试从试卷快照读取临床信息及影像，不读取实时资料库答案。已开放的教学病例不能承诺闭卷保密；试卷发布前提示教师检查资料公开范围。 |

## 3. 专项规则与依赖

与教师共用病例、影像和版本，不复制第二份库；完整迁移对照见配套材料。无可靠标定不显示真实倍率或测量。
