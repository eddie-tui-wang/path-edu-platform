# 学生端｜考试中心与作答

## 1. 产品定义

- **这是什么功能：** 完成已分配考试的阅读、选择题／简答题、图像标注和整卷提交。
- **帮助用户解决什么问题：** 让题目、临床信息、图像证据和答案处于一个连续流程中。
- **为平台带来什么价值：** 产生可复核、版本固定的答卷。

承接旧总稿 F08—F14；共用权限、阶段与数据版本规则见[总纲](../../独立病理教学网站MVP需求稿_v0.1.0.md)。本稿为目标产品规则，非实现完成声明。

## 2. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| S-EXAM-01 | 找到考试 | 待开始／进行中／已提交列表 | 只列已发布且分配给当前账号的试卷；展示题型组成、时长、开放状态、题数和总分。教师草稿不可见。 |
| S-EXAM-02 | 确认开始 | 考试说明与开始按钮 | 确认后创建唯一答卷，记录试卷版本和开始时间；每卷每学生一次机会。截止取考试关闭时间与个人时限较早者；恢复不重新计时。 |
| S-EXAM-03 | 阅读病例 | 桌面题号栏／图片区／作答区，窄屏标签页 | 病例病史可折叠但始终可找回；选择病例图片平移缩放，切题保存该题答案与视野。不同病例不得共用错误图片。 |
| S-EXAM-04 | 逐题作答 | 单选、多选、简答组件 | 按题目配置显示输入，选择题不额外强制填写诊断长表单；简答按题干填写，总体形态独立文本，不自动拼接区域描述。试卷可全选择、全简答或混合。 |
| S-EXAM-05 | 标注证据 | 矩形／点／多边形与区域说明 | 题目配置标注为可选或必需；绑定题号、答卷、影像版本及原图坐标。每个区域填写形态判断，诊断、鉴别及免疫组化按题干指定填写。删除区域二次确认。 |
| S-EXAM-06 | 保存与恢复 | 保存中／已保存／失败及剩余时间 | 自动保存答案和标注；当前原型明确为本机保存。保存失败保留输入并允许重试；刷新可恢复，不能仅凭计时器显示成功。 |
| S-EXAM-07 | 整卷提交 | 未作答题清单、提交确认、只读答卷 | 允许确认后提交含空题的答卷；必需标注未完成作为未完成项提示。重复点击不得生成多份答卷；截止锁定编辑，断网迟交按总纲规则处理。 |
| S-EXAM-08 | 等待结果 | 已提交／分析中／待复核／已发布 | 不立即展示未发布参考答案。选择题程序计分；简答分析失败标待处理而非零分。提交后可查看自己的原始答案。 |

## 3. 专项规则与依赖

具体题型计分和发布规则见总纲；模拟试卷契约见配套材料。当前教师发布与旧学生固定作答页面尚需接通，不能把预览算作考试完成。
