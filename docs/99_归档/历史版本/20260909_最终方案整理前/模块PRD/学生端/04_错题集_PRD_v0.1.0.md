# 学生端｜错题集

## 1. 产品定义

- **这是什么功能：** 汇总本人已发布结果中的错误题目和简答扣分点。
- **帮助用户解决什么问题：** 从薄弱点快速回到原题、解析和图像证据。
- **为平台带来什么价值：** 形成与答卷一致的复习资料。

承接旧总稿 F17（错题）；共用权限、阶段与数据版本规则见[总纲](../../独立病理教学网站MVP需求稿_v0.1.0.md)。本稿为目标产品规则，非实现完成声明。

## 2. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| S-WRONG-01 | 进入错题 | 类型筛选与错题列表 | 只从本人已发布结果产生；题数与考试数来自真实记录。移除“以下为固定流程示例……”长横幅；必要时仅以示例标签标识种子内容。 |
| S-WRONG-02 | 筛选薄弱点 | 临床／区域／形态／诊断鉴别／辅助检查 | 支持按考试、能力维度和题型筛选；没有错误显示空态，不填充固定假错题。 |
| S-WRONG-03 | 查看解析 | 本人答案、评分依据、图像入口 | 选择题按题入集，简答按扣分点归组并关联原题；明确得分与扣分原因，可定位原题图片和标注。 |
| S-WRONG-04 | 跟随成绩修正 | 修订标识与集合刷新 | 已发布评分修改后重算归集；不删除原答卷和修订记录。本期不增加错题重答、掌握打卡或自动移除。 |

## 3. 专项规则与依赖

重复说明横幅不再作为页面默认结构；演示来源在对象标签或统一环境说明内简洁表达。
