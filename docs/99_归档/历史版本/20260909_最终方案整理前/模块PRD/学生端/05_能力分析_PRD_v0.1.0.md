# 学生端｜能力分析

## 1. 产品定义

- **这是什么功能：** 从已发布考试结果汇总五维能力证据和改进建议。
- **帮助用户解决什么问题：** 看清具体薄弱点而非仅看到一个总分。
- **为平台带来什么价值：** 连接考试、错题和针对性学习。

承接旧总稿 F18；共用权限、阶段与数据版本规则见[总纲](../../独立病理教学网站MVP需求稿_v0.1.0.md)。本稿为目标产品规则，非实现完成声明。

## 2. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| S-ABILITY-01 | 进入总览 | 五维图、样本量、统计范围 | 五维为临床信息整合、关键区域识别、形态学判断、诊断与鉴别、辅助检查规划。仅本人已发布且有维度映射的得分点参与。 |
| S-ABILITY-02 | 查看维度 | 维度明细、覆盖题数和证据 | 展示统计口径、规则版本和考试范围；未覆盖维度显示暂无证据，不补零或伪造雷达图。 |
| S-ABILITY-03 | 追溯题目 | 关联考试／错题／标注入口 | 点击维度定位相关题目得分点，不跳无关固定病例；返回保留所选维度。 |
| S-ABILITY-04 | 阅读建议 | 证据、改进动作、验证方式 | 建议须引用已有扣分点；无已接入AI时只显示规则统计或明确示例，不宣称智能生成。 |

## 3. 专项规则与依赖

实施前置依赖：专家确认维度映射、权重、最低样本及可比性，见依赖清单；不同试卷不可不加条件地生成成长趋势。
