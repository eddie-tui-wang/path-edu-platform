# 学生端｜考试记录与结果

## 1. 产品定义

- **这是什么功能：** 查询本人考试记录并回看已发布结果、原始作答与题目证据。
- **帮助用户解决什么问题：** 区分已提交、待评分和正式可看的结果。
- **为平台带来什么价值：** 提供复习和评分修正的可靠历史入口。

承接旧总稿 F16、F17（记录）；共用权限、阶段与数据版本规则见[总纲](../../独立病理教学网站MVP需求稿_v0.1.0.md)。本稿为目标产品规则，非实现完成声明。

## 2. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| S-RESULT-01 | 查询记录 | 时间／状态筛选及记录列表 | 仅本人答卷，展示考试名称、提交时间、成绩发布状态；未发布不显示分数和参考答案。 |
| S-RESULT-02 | 查看结果 | 总分、题目导航、结果版本 | 结果由教师整卷发布后开放；保留试卷版本、评分版本和发布时间。没有答卷显示空态，不以固定示例冒充本人记录。 |
| S-RESULT-03 | 逐题回看 | 原答案与参考答案并列、扣分点 | 选择题显示选项与判定；简答显示得分点、未满足点、复核意见。原始答案只读，缺参考依据直接显示缺失状态。 |
| S-RESULT-04 | 定位证据 | 题目绑定图片、本人区域、开放参考区域 | 打开该次考试的历史影像；标注与形态描述逐一对应。不将当前库的新图覆盖旧答卷。 |
| S-RESULT-05 | 查看修正 | 修订原因、前后分数和发布时间 | 教师修正发布后显示最新版本与修正记录；同步更新错题与能力统计。返回列表保留筛选位置。 |

## 3. 专项规则与依赖

诊断性结论为教学参考；前端不生成不存在的答卷、扣分理由或个人能力。
