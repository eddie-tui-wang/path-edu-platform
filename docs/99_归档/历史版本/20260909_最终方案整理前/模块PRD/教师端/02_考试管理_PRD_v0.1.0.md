# 教师端｜考试管理

## 1. 产品定义

- **这是什么功能：** 从病例选题、手工出题、组卷发布到答卷复核和成绩发布。
- **帮助用户解决什么问题：** 让教师清楚每一步准备什么、谁能看见、何时可以修改。
- **为平台带来什么价值：** 建立师生共用同一试卷和评分版本的教学闭环。

承接旧总稿 F05、F06、F14、F15；共用权限、阶段与数据版本规则见[总纲](../../独立病理教学网站MVP需求稿_v0.1.0.md)。本稿为目标产品规则，非实现完成声明。

## 2. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| T-EXAM-01 | 进入考试管理 | 草稿／已发布／已结束列表 | 列表提供名称、题型、题数、总分、发布对象和状态，主操作新建试卷；草稿编辑、已发布查看、已交卷进入阅卷。 |
| T-EXAM-02 | 配置试卷 | 基础信息表单与步骤导航 | 填写名称、全选择／全简答／混合、时长、开放关闭时间和目标学生；允许保存不完整草稿，禁止不完整发布。 |
| T-EXAM-03 | 选病例 | 授权资料选择器、临床和图片预览 | 可从病理资料发起出题或在试卷内选择病例；引用固定版本。一卷可包含多个病例，一病例可对应多题。检查学生可见材料不泄漏答案。 |
| T-EXAM-04 | 编写题目 | 题号列表＋题目编辑区＋学生视图预览 | 手工编写单选、多选或简答；单选／多选填写选项和正确答案；简答填写参考答案、分点评分及证据来源。每题配置分数、能力映射与是否要求标注。第一期不自动AI出题。 |
| T-EXAM-05 | 整理题序与分值 | 题目列表、总分及错误定位 | 可增删调整题序；更换题型时提醒不兼容答案处理。单选只允许一个正确项，多选至少两个；各简答得分点之和等于题分。混合卷必须同时含选择和简答。 |
| T-EXAM-06 | 预览与检查 | 学生预览、发布检查清单 | 逐题验证病例图片可用、答案／评分点齐全、学生有效、时间合理、题型匹配；错误直接定位题目，不只给笼统提示。预览不生成学生答卷。 |
| T-EXAM-07 | 确认发布 | 发布摘要、学生名单、版本号 | 冻结题目、病例、图片和评分规则快照；在同一数据源生成已发布试卷，目标学生列表立即可见。发布后只读，变更复制为新版本；未开始可取消，已有答卷必须保留。 |
| T-EXAM-08 | 监控交卷 | 学生提交状态与待阅卷列表 | 区分未开始、进行中、已提交；未提交不伪造成已交卷。选择题确定性评分；简答AI任务异步，失败可重试或人工处理，空答零分与调用失败不同。 |
| T-EXAM-09 | 逐卷复核 | 原答案、图像证据、初评分、修改理由 | 教师仅复核授权试卷；原答案只读。简答逐得分点评分，修改初评需理由；未接AI时允许人工评分，不制造AI结果。 |
| T-EXAM-10 | 发布成绩 | 待处理数量、整卷发布确认 | 所有需评分答卷处理完成后整场考试统一发布成绩；未完项阻止发布并提供定位。学生结果、错题、能力使用同一发布版本。 |
| T-EXAM-11 | 后续修正 | 修正原因、版本和受影响对象 | 修正已发布分数需留存原版本与原因，重新发布后更新学生结果及汇总；不修改已提交原答案。 |

## 3. 专项规则与依赖

完整出题路径、现状差距及默认试卷契约见配套材料；本模块规则不等于当前固定学生作答页已经接通。
