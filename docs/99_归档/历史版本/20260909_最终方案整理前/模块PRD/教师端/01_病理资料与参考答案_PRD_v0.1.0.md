# 教师端｜病理资料与参考答案

## 1. 产品定义

- **这是什么功能：** 维护标准库／院方库病例、影像、参考区域与评分所需资料。
- **帮助用户解决什么问题：** 把找素材、阅片和准备教学参考整合到同一资料入口。
- **为平台带来什么价值：** 形成考试和教学记录共用的版本化内容源。

承接旧总稿 F03、F04；共用权限、阶段与数据版本规则见[总纲](../../独立病理教学网站MVP需求稿_v0.1.0.md)。本稿为目标产品规则，非实现完成声明。

## 2. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| T-LIB-01 | 查找资料 | 来源、部位、收藏、卡片／列表 | 完整承接旧切片图书馆在教学范围内的检索、分类、收藏、详情与阅片；具体真实实现差距见迁移分析。只显示授权病例，数字从可见数据计算。 |
| T-LIB-02 | 新建或导入病例 | 新增按钮、临床表单、图片上传 | 教师在院方库新建，填写病例名、临床病史、来源和素材权限。JPG／PNG多图上传显示进度与失败项；标准库写入须额外授权。学生不拥有本入口。 |
| T-LIB-03 | 整理临床与影像 | 分组临床字段、缩略图、顺序和封面 | 病例与图片为一对多；图片有独立编号、尺寸和版本。临床信息与参考答案分区，禁止只改显示标题却仍关联旧图。 |
| T-LIB-04 | 阅片并维护参考 | 主图、参考区域列表、形态描述 | 可平移缩放切图；维护参考区域及形态、最可能诊断、鉴别和免疫组化思路、依据来源及确认状态。图片标注使用原图坐标。 |
| T-LIB-05 | 保存版本 | 保存状态、引用提醒 | 编辑有草稿和保存结果；已被考试引用的版本不可覆盖。更新病例生成新版本，不改变历史答卷。 |
| T-LIB-06 | 进入教学或出题 | 用于出题／用于教学记录 | 传递病例ID和版本到考试草稿或教学记录；收藏只改变个人偏好，不改变资料授权。返回保持筛选。 |

## 3. 专项规则与依赖

临床参考和评分医学正确性须由专家确认。完整迁移指教学资料库能力，不包括科研项目、模型训练、GPU调度、PACS实时接入或第一期WSI。

实施条件统一记录在[实施依赖与待确认清单](../../实施依赖与待确认清单.md)。页面组件沿用现有六院绿色 Design System。截图示意列是设计要求，并非已完成页面截图。
