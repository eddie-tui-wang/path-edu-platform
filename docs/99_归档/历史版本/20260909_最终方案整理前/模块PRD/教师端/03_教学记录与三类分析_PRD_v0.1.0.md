# 教师端｜教学记录与三类分析

## 1. 产品定义

- **这是什么功能：** 组织病例讲解记录，并查看轨迹、互动问答及诊断一致性证据。
- **帮助用户解决什么问题：** 把教学过程与具体图像和讲解依据关联起来。
- **为平台带来什么价值：** 为教师画像提供可追溯输入。

承接旧总稿 F19—F22；共用权限、阶段与数据版本规则见[总纲](../../独立病理教学网站MVP需求稿_v0.1.0.md)。本稿为目标产品规则，非实现完成声明。

## 2. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| T-RECORD-01 | 选择病例开始 | 病例选择、教学记录列表 | 必须先选授权病例和图片版本再进入记录；列表显示主题、病例、时间和处理状态。 |
| T-RECORD-02 | 记录过程 | 图片区、记录控制、时间线 | 本期录音转写及同步回放仅前端示例UI，不实际采集声音；按钮状态与示例时间线不得宣称已生成真实记录，不增人工录入替代流程。 |
| T-RECORD-03 | 查看记录材料 | 轨迹／文本／互动三个证据区 | 真实服务接入后保存图片平移缩放和标注事件、录音及带时间戳转写；共同时间基准。原始文本、人工修订分别保存，不能凭声音猜身份。 |
| T-RECORD-04 | 分析讲解轨迹 | 视野停留和关键区域回看 | 程序汇总事件，模型结合讲解文本解释策略；停留时间不直接等于教学质量，普通图片覆盖率不冒充全WSI覆盖率。 |
| T-RECORD-05 | 分析互动问答 | 问答片段、回应、证据定位 | 关联提问、回答与追问片段；缺音频或角色不明显示局限，不凭次数判断优劣。 |
| T-RECORD-06 | 分析诊断一致性 | 教师观点、参考依据与差异 | 分别呈现讲解中的判断、所用参考及差异证据；无已确认参考不输出权威准确率。三类任务独立状态，部分失败不抹去成功结果。 |

## 3. 专项规则与依赖

实施前置依赖：转写服务、录音告知、时间戳和专家分析规则。已确认延期，不作为当前前端完成的阻塞；不得将假UI纳入真实采集验收。

实施条件统一记录在[实施依赖与待确认清单](../../实施依赖与待确认清单.md)。页面组件沿用现有六院绿色 Design System。截图示意列是设计要求，并非已完成页面截图。
