# 教师端｜能力画像与发展建议

## 1. 产品定义

- **这是什么功能：** 按专业知识、教学技能、AI应用和资源建设生成教师画像及建议。
- **帮助用户解决什么问题：** 把教学记录分析转成可操作的改进事项。
- **为平台带来什么价值：** 建立基于证据的教师能力发展闭环。

承接旧总稿 F23、F24、F20；共用权限、阶段与数据版本规则见[总纲](../../独立病理教学网站MVP需求稿_v0.1.0.md)。本稿为目标产品规则，非实现完成声明。

## 2. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| T-ABILITY-01 | 进入画像 | 四维摘要、范围和证据量 | 默认本人；查看其他教师须单独授权。展示数据范围与规则版本，不按职称猜分、不把管理员权限等同画像读取权。 |
| T-ABILITY-02 | 查看维度依据 | 维度卡片、具体教学记录及资源贡献 | 专业知识关联已确认参考比较，教学技能关联轨迹和互动，AI应用关联实际使用与采纳修订记录，资源建设关联本人授权内容贡献。无证据显示不足。 |
| T-ABILITY-03 | 使用教学辅助AI | 问题输入、引用来源、采纳／修订／弃用 | 只在教师准备与教学场景开放，学生考试不提示答案；保留问答与反馈作为AI应用证据。规则指标由程序算，文本解释才调用模型。 |
| T-ABILITY-04 | 阅读个性化建议 | 问题证据→行动→应用场景→验证方式 | 每条建议链接原始证据并说明如何改进；不输出空泛排名或凭少量记录推断整体能力。 |
| T-ABILITY-05 | 回看与更新 | 记录详情、更新状态 | 进入具体记录保留来源维度和筛选。新有效证据或评分版本产生后重算并保存版本；失败时保留原可用结果及时间。 |

## 3. 专项规则与依赖

实施前置依赖：四维权重、最低证据量、AI接口及知识来源；确认前只展证据与规则待确认，不展示伪精确分数。
