# 公共与管理｜授权与任务后台

## 1. 产品定义

- **这是什么功能：** 管理数据访问范围及分析异常，不混入教师评分权限。
- **帮助用户解决什么问题：** 避免管理员越权查看内容或把失败任务当成有效结果。
- **为平台带来什么价值：** 支撑真实服务阶段的可追溯运营。

承接旧总稿 F25；共用权限、阶段与数据版本规则见[总纲](../../独立病理教学网站MVP需求稿_v0.1.0.md)。本稿为目标产品规则，非实现完成声明。

## 2. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| C-OPS-01 | 授权数据 | 角色与对象范围配置 | 学生仅分配考试及自己的结果；教师仅自有／明确授权病例与试卷；标准库维护、教师画像读取需独立授权。管理员默认管理账号，不自动继承临床内容权。 |
| C-OPS-02 | 查询分析任务 | 状态、对象、输入版本和更新时间 | 查看元数据及错误原因，不默认打开病史和答案；按等待／运行／成功／部分失败／失败／依据不足筛选。 |
| C-OPS-03 | 处理异常 | 重试、失败说明、任务历史 | 重试保持输入版本与幂等标识；权限失效阻止处理。管理员不得改分或修改参考医学结论。 |
| C-OPS-04 | 审计与用量 | 操作记录和使用量 | 真实服务记录操作者、对象、动作与时间；日志不记录密码或完整密钥。当前本机演示记录不能称安全审计，模型预算达到阈值应限制调用并告知。 |

## 3. 专项规则与依赖
