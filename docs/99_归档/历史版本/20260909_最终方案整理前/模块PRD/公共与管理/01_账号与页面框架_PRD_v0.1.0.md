# 公共与管理｜账号与页面框架

## 1. 产品定义

- **这是什么功能：** 提供角色入口、账号维护和一致的页面操作框架。
- **帮助用户解决什么问题：** 减少冗余导航、长表单堆叠和不统一按钮。
- **为平台带来什么价值：** 让教学功能具备清楚的权限和稳定的操作体验。

承接旧总稿 F01、F02；共用权限、阶段与数据版本规则见[总纲](../../独立病理教学网站MVP需求稿_v0.1.0.md)。本稿为目标产品规则，非实现完成声明。

## 2. 核心流程与功能需求

| 编号 | 能力 | 截图示意说明 | 文字说明 |
|---|---|---|---|
| C-ACCOUNT-01 | 登录与进入 | 品牌、账号区、角色侧栏 | 顶部保留品牌、当前身份、改密和退出；删除管理后台／学生端等重复角色导航及无效帮助中心。功能导航集中在侧栏，不另做单项顶栏。 |
| C-ACCOUNT-02 | 查看账号 | 页标题＋新增按钮＋搜索筛选＋账号表 | 管理员页面以账号列表为主任务；按账号／姓名、角色、状态查找，显示结果数量与空态。管理员不渲染无意义空侧栏占位。 |
| C-ACCOUNT-03 | 新增账号 | 新增对话框或抽屉、字段校验 | 点击新增后展示账号、姓名、角色和初始密码；成功关闭表单并定位新增记录，失败保留输入。不要在列表下永久展开巨大新增表单。 |
| C-ACCOUNT-04 | 管理单个账号 | 角色、启停、重置密码操作 | 当前账号标识清楚；禁止停用自己或移除最后一个可用管理员。危险操作确认并反馈结果，演示模式只修改本浏览器账号。 |
| C-ACCOUNT-05 | 查看记录与恢复 | 次级操作菜单、恢复确认对话框 | 操作记录作为次级区域；恢复初始演示账号放在更多操作／演示设置，使用现有Design System按钮，不出现裸HTML按钮。确认准确列明将重置哪些账号数据，不默认清除考试和病例。 |
| C-ACCOUNT-06 | 统一内容表达 | 状态标签、保存提示和必要告知 | 删除学生各页面重复的固定流程示例长横幅，不反复解释技术实现。演示对象以简短示例标签区分；保留必要的禁止上传真实患者资料等告知。 |
| C-ACCOUNT-07 | 真实权限演进 | 真实登录、改密、停用及会话状态 | 当前浏览器演示账号不提供真实隔离。接真实服务后由服务端在列表、详情、文件、分析和写入中检查身份与对象授权，密码不明文存储。 |

## 3. 专项规则与依赖

本次浏览器意见C01按钮、C02管理员层级、C03冗余导航、C04重复横幅均在此定义，页面尚未修改。正文16px、辅助14px，支持窄屏及200%缩放，键盘焦点可见。
