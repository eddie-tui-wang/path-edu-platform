## 4. 第一期必须落地的最小数据契约

| 对象 | 必须保存的信息 | 不变规则 |
|---|---|---|
| 病例及版本 | 病例ID、机构／库归属、临床字段、显示字段、影像版本列表、模拟标识、来源及授权 | 临床公开资料与标准答案隔离；发布引用版本不可覆盖 |
| 影像资源 | 影像ID、版本、类型`image`或`wsi`、原始宽高、坐标系、处理状态、权限归属、源文件校验信息、可用能力 | 读取接口输出展示描述，不把私有对象路径当永久访问地址；类型可扩展 |
| 标注 | 标注ID、影像版本、题目／教学记录、作者、形状和点集、形态文字、坐标基准 | 原点左上、单位原始像素，WSI用level-0；变换由阅片器完成，不持久化屏幕像素作为医学位置 |
| 视野事件 | 会话ID、影像版本、相对时间、事件类型、原图视野矩形、缩放、方向 | 方向未开放时固定原始方向；普通图片与WSI使用同一原图坐标表达 |
| 题目及答卷 | 题型、分值、能力映射、题目／选项／病例／标准／规则版本、学生答案、保存修订号、服务器时间 | 题型在试卷层校验，答案按题保存；锁定后不可改写 |
| 教学记录 | 教师与机构、关联影像、起止时间、音频片段序号与偏移、缺失片段、转写／校订版本、AI使用反馈 | 音频与事件共享会话时间基准；原始录音不被校订文本覆盖 |
| 分析与发布结果 | 输入版本集合、模型／提示／规则版本、状态、逐项结果、证据、复核人和发布版本 | 任务运行不等于结果发布；重试幂等、历史可追溯 |

能力描述至少区分平移缩放、标注、瓦片、多分辨率和物理标定。第一期图片具备前两项；WSI解析后按实际能力开放其余项。不要为了二期提前部署未使用的WSI服务或购买GPU。

## 5. 两期演进与历史数据

| 项目 | 第一期 | 第二期 |
|---|---|---|
| 上传处理 | JPG／PNG签名上传、尺寸／内容校验、缩略图 | 新增大文件分片续传、格式解析、瓦片与标定；具体大小上限由D09样本确认 |
| 阅片 | 多张独立图片、相对缩放、原图坐标标注 | 同一组件能力接口加载WSI，多级瓦片、导航、准确标定 |
| 业务服务 | 账号、病例、考试、录音、AI、画像真实运行 | 继续复用，不替换全部后台 |
| 历史数据 | 模拟数据显式标识，演示分析不并入医学能力基线 | 旧图片继续可读，新WSI建立独立影像版本；混合素材可共存 |
| 模型 | 基于确认标准的文本分析 | 默认仍沿用；病理图像模型另立验证，不随WSI自动启用 |

从图片映射到WSI仅在明确同源、裁剪范围、缩放及方向转换并通过至少三个参考点核验时进行；这是后续受控转换，不是默认迁移步骤。无映射则保持独立图片证据，禁止用宽高比例盲目拉伸。已发布答卷始终回看原影像与原区域。
