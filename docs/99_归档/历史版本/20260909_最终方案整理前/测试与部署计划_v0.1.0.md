# 测试与部署计划 v0.1.0

## 1. 当前状态与验收分层

本文件是后续执行计划，尚未建设、运行或部署独立网站。此次只完成文档结构、来源、编号与链接检查，不能记为下面的业务用例通过。现有原型HTML及源码字符串测试不等于真实功能验收。

| 验收层 | 使用数据 | 完成标准 |
|---|---|---|
| 第一期流程验收 | 明确标识的模拟图片、病史、规则和测试账号 | 真实上传／存储／作答／录音／服务调用／结果发布／证据回看闭环；不使用假成功替代外部调用 |
| 第一期医学评价验收 | 有权使用、经专家确认的图片、答案和量表 | 固定样本与专家逐项对照，达到D04确定的标准；未达到只能声明流程可用 |
| 第二期WSI验收 | 脱敏并授权的实际格式样本 | 格式、原图坐标、瓦片、标定与性能通过，同时第一期记录不回归 |
| 课题效果验证 | 课题组设计的教学实践与研究数据 | 不包含于本次软件测试；PDF中的p<0.05、满意度提升≥15%是实证目标，不作为研发可保证指标 |

## 2. 测试准备与记录规范

准备独立管理员、教师A／B、学生A／B及无授权账号；测试环境另建隔离机构验证组织边界，但不新增多机构协作产品功能。素材覆盖多图病例、已确认与未确认标准、模拟病例、缺失字段、损坏文件及重名文件。至少具备一份全选择、一份全简答、一份混合卷，包含必需标注与不需要标注的题目。

自动化分层：单元测试覆盖计分、坐标、规则及状态；接口集成测试覆盖权限、数据库、保存、上传和任务；浏览器端到端测试覆盖两个完整闭环；人工检查验证录音、可读性及真实院外网络。模拟外部服务只用于失败与边界测试，端到端服务验收必须有真实调用证据。

每条执行记录保存：测试ID、需求ID、环境、应用版本、数据与规则版本、执行人、日期、预期／实际结果、证据、问题编号和复测结论。状态为未执行／通过／失败／依赖阻塞；未执行不得标通过。日志及截图去除身份和密钥信息。

两条必须留存完整证据的E2E：

1. 管理员建账号 → 教师上传多图病例 → 确认参考与评分 → 发布混合卷 → 学生阅读、作答标注、提交 → 真实AI分析 → 教师复核发布 → 学生查看错题与五维证据。
2. 教师打开病例 → 开始真实录音与图片轨迹 → 提问AI并记录反馈 → 结束与校订 → 三类分析 → 四维画像／数据不足状态 → 从建议返回录音及图片区域。

## 4. AI评测与性能方案

AI基准集逐项覆盖A01—A11。简答样本至少包含正确、部分正确、错误、同义表达、正确诊断但缺依据、合理但标准未覆盖；教师样本含无问答、术语转写错误、诊断修正、无参考诊断及资源贡献归属。每组保存专家期望与原始来源。开发冒烟每组至少1例，正式医学评测样本规模与阈值由D04确认，不能把冒烟当准确率评测。

记录逐要点符合率、分数差异、错误引用、无依据断言、待复核率、同样本三次运行波动、耗时和单次费用。涉及身份泄露、捏造来源或越权读取的结果不得通过上线门禁；医学质量阈值未确认则标记医学验收阻塞，不宣布合格。

20人并发为已确认容量目标；第一期建议负载脚本为1名管理员、3名教师、16名学生持续30分钟，同时执行阅图、自动保存、2路录音和2个图片上传任务。该配比和时长是工程测试默认值，不代表真实日常负载。业务请求建议以P95不超过2秒、错误率低于1%作为待D02确认的性能门槛；文件传输和外部AI耗时单独统计，不混入普通请求门槛。最终上传大小、图片像素、录音时长及服务延迟阈值见D03、D05，未确认前记录实测而非承诺。

## 5. 部署结构与环境隔离

部署基线为“EdgeOne网站入口＋国内业务服务＋关系数据库＋私有对象存储＋后台任务”。建议关系数据库采用PostgreSQL、对象存储采用腾讯云COS；此为待资源核验的落地建议，不是已购买事实。第一期后台任务处理图片、ASR和文本分析；第二期再增加WSI解析工作进程。不为第一期购买病理模型GPU。

| 环境 | 数据与凭据 | 访问与发布规则 |
|---|---|---|
| 开发 | 本地／独立开发库，模拟种子，测试凭据 | 不接旧平台生产数据；可模拟外部错误，但真实调用验收另留证据 |
| 测试 | 独立测试库及文件空间，授权测试素材，限额API凭据 | 限定测试账号，执行E2E／安全／恢复演练；不能污染正式画像 |
| 正式试用 | 独立教学数据库、私有对象空间、正式服务端密钥 | 仅邀请账号；不开放任意自注册；审批后发布；禁止测试脚本写入真实答卷 |

原平台配置、身份请求头、数据库和域名不复制为新站默认配置。浏览器只取得授权上传凭证和临时文件地址，图片／音频直接进入私有存储；业务服务校验上传结果。不得将文件、患者正文或音频作为公开静态素材部署。第二期GB级WSI不能经短时请求同步完成解析。

EdgeOne边缘函数与其他云函数运行环境不同，部署前按实际产品核对限制；不默认边缘函数适合录音或WSI长任务。[EdgeOne边缘函数官方文档](https://pages.edgeone.ai/document/edge-functions)，核对日期2026-09-07。保留国内网站方向，但具体区域、域名、备案及组织数据审批由D01确认；可访问某个默认地址不能证明全部业务数据在境内。

## 6. 发布、安全与回退检查

### 发布前

1. D01—D08中当前发布所需依赖有负责人及处理结论；未落实事项明确是否阻断流程或医学验收。
2. 新仓库和独立环境配置确认，依赖版本锁定；数据库变更脚本在测试环境验证，不直接作用于旧平台。
3. 密码使用适当的单向口令哈希；HTTPS、会话失效、登录限速、变更请求保护及RBAC检查通过；文件访问不得公共缓存。
4. 采集告知、素材授权和允许发送至AI服务的数据范围确认；使用模拟数据也不得含真实患者标识。
5. 两条E2E、T01—T20适用用例完成；阻断性问题关闭。AI医学验收未通过时只能标注“模拟流程试用”，不得展示医学有效性承诺。
6. 配置任务失败、连续API认证失败、调用额度和存储容量告警；日志只含追踪ID、状态及必要元数据。告警接收责任人见D07。

### 备份与恢复

数据库与对象存储建立对应备份清单，确保影像版本、音频和数据库引用一致。初始建议每天数据库备份、对象版本保护及每次上线前快照，恢复点不超过24小时、恢复服务不超过4小时；均为待D02确认并演练的目标，不是既有保障。数据保留期限、删除流程、备份保留及费用见D06，不设置未经确认的永久保留或自动删除真实资料。

恢复演练必须在隔离环境进行：恢复病例及影像 → 恢复答卷和发布结果 → 恢复教学音频与证据 → 验证授权 → 验证引用完整。记录实际恢复时间和缺失范围。

### 发布与回退

先内部测试，再邀请少量六院账号试用，达到容量验证后开放到20人。记录发布版本、数据库版本、模型配置和数据规则版本。应用故障优先回退应用；数据库采用向后兼容变更，不盲目执行破坏性回滚。若需恢复备份，先停止写入并明确可能丢失的时间段，由负责人确认后执行；不能通过回滚悄悄丢弃已提交答卷。

回退后复测登录、图片读取、未完成答卷恢复、成绩和教学证据。旧平台不在新站回退操作范围内。
