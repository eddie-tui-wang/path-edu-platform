# 第一期无数据库演示

默认入口为 /，真实账号验证入口保留在 /account。演示入口不请求账号 API，也不在真实账号服务故障时自动启用。

## 已实现

- 三个公开演示身份，分别进入学生、教师、管理员界面。
- 浏览器本地创建演示账号、调整角色、启用停用、重置密码与自行改密。
- 演示账号和最近 100 条操作记录保存于 localStorage；退出后保留，清理浏览器数据后丢失。
- 原有学生作答、病例查看和教师分析界面继续复用；原有固定结果仍是示例，不表示已接通 AI。
- 真实账号服务与数据不变。它仍然需要数据库；无数据库时不应使用 /account 验证业务。

## 使用与验证

1. 打开 /，使用页面列出的公开演示账号登录。
2. 学生检查考试列表与病例；教师检查四维画像和演示教学记录。
3. 管理员创建演示学生，退出后使用新账号登录；刷新后重新登录，账号仍存在。
4. 停用该演示学生，验证不能登录；启用后重新验证。
5. 自行改密后使用新密码重新登录；错误密码应被拒绝。
6. “恢复初始演示账号”仅清除新增演示账号和账号修改，并重建账号操作记录，不清除考试草稿、不修改真实账号。

## 边界

演示密码明文保存在浏览器中，并非身份认证或权限安全方案。不同设备不共享数据；当前标签页登录状态不作为跨标签页会话控制。不得存储真实密码、患者资料或正式成绩。

本次未补齐真实考试评分、资源授权、跨用户成绩联动或 AI 服务。教师录音、转写和分析仍是明确标注的示意效果。需要这些真实能力时另行接入后端，不把演示结果当作已验收能力。

未增加依赖、未购买资源、未部署。已有数据库代码保留供后续使用。
