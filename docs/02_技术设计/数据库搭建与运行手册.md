# 数据库搭建与运行手册 v0.1.0

日期：2026-09-08。当前没有购买云数据库，没有把本轮账号改动发布到EdgeOne。用户已确认此前部署普通窗口、无痕和手机均可访问。

## 1. 先理解要开通什么

建议技术选型为 PostgreSQL。腾讯云可提供托管 PostgreSQL；EdgeOne继续托管网站。两者是两项资源，不需因此购买Cloudflare。图片后续放私有对象存储，不把大文件直接塞进账号数据库。

你已有100元／月云＋AI预算，不能在不知道报价和网络方式的情况下承诺托管数据库一定够用。先查看报价，不点击付款。若托管PG超预算，可评估已有院方PG或同区域应用与PG的小型服务器方案；后者需要自行承担补丁、备份、故障恢复，并不天然更省总成本。本轮不切换云厂商或自动购买服务器。

## 2. 本地体验（无需买数据库）

工作目录为独立项目。安装锁文件依赖，将 `.env.example` 复制为被忽略的 `.env.local`，保留本地前三项配置。下面命令只在项目目录运行：

```sh
pnpm install --frozen-lockfile
pnpm db:migrate
pnpm db:bootstrap -- --generate-local
pnpm dev
```

若包管理器未透传参数，也可直接运行：

```sh
node --env-file=.env.local scripts/database.mjs bootstrap --generate-local
```

打开 http://localhost:3002 。本地初始管理员凭据位于 `.local/首次管理员登录.txt`，只在首次初始化生成，不打印到日志、不提交仓库。首次登录改密后删除这份凭据。初始化发现任何账号即拒绝执行，不会覆盖已有管理员。

若本机已经运行自动浏览器验收，初始管理员的强制改密已验证，凭据文件会安全更新为“当前密码”；建议你登录后再次改密，然后删除该文件。`qa_`开头的账号为已停用验收账号，不是正式师生账号。

PGlite文件在 `.local/database`，服务重启后仍保留。只允许一个Node进程打开该目录：启动开发服务前做迁移；迁移／备份前停止使用该目录的开发服务。不要将此目录复制到EdgeOne。生产模式拒绝使用PGlite。

首次初始化失败：保留报错并排查，不能反复删库。遗失本地管理员密码时先确认是否需要保留本地数据，再由开发人员处理；没有公开“重置管理员”后门。

## 3. 腾讯云控制台：你现在只需确认的四项

| 步骤 | 怎么看 | 发给我什么（不含密钥） | 停止条件 |
|---|---|---|---|
| 1 | 控制台搜索“云数据库 PostgreSQL”，先看是否已有独立可用实例 | 有／没有；若有，地域、PG版本、规格、到期情况 | 不将旧生产库作为本项目测试库 |
| 2 | 若没有，进入购买配置页但不下单；选择计划部署区域并查看最低合适规格 | 地域、规格、存储、含备份／流量的报价及续费价截图 | 总费用与AI预算不兼容时不购买 |
| 3 | 查看候选实例的网络说明；EdgeOne实际Node运行位置与出口是否能到达它 | 现有实例网络页或官方支持答复；只要能力信息 | 同一云厂商不代表自动能访问VPC；不要放行0.0.0.0/0图省事 |
| 4 | 查看备份和SSL能力；确认现有域名是否稳定可供登录 | 备份保留／费用、SSL选项、稳定域名情况 | 不把临时预览凭证发给所有老师作为长期入口 |

由开发方负责判断配置可行性，不要求产品负责人自行编写SQL。暂时不用开通KV；本方案不依赖它。

## 4. 方案确认后，由实施人员执行

1. 创建独立开发／测试／正式数据库。小规模可共享一台实例的不同库和不同用户，但这只是逻辑隔离，并非故障隔离。正式库不得放自动测试种子数据。
2. 选择离Node服务近且符合医院要求的区域。确认是VPC连通还是受控TLS公网；先验证EdgeOne到PG连接。不具备可靠连通时调整应用后端部署位置，不通过放开所有IP规避问题。
3. 开启并验证SSL，使用证书匹配的主机名；需要私有CA时配置DATABASE_CA。驱动强制证书校验，不使用 `rejectUnauthorized:false`。腾讯云SSL配置见[官方指南](https://cloud.tencent.com/document/product/409/115986)。
4. 创建两类数据库用户：迁移用户可DDL；运行用户只能读写本项目表。运行用户不是数据库超级用户、不是表所有者。审计只授予SELECT/INSERT，不授予UPDATE/DELETE；institutions与schema_migrations只读。users/sessions/resource_grants/login_limits按当前API所需授权，后续细化。
5. 在受控终端以迁移用户运行建表脚本，检查schema_migrations只有预期版本。迁移不是每次请求自动执行。
6. 以一次性初始化环境设置BOOTSTRAP_USERNAME、BOOTSTRAP_PASSWORD及机构名，运行 `scripts/database.mjs bootstrap`。密码由用户安全设置，勿发聊天、勿留命令历史。完成后撤掉临时变量。
7. EdgeOne项目环境变量中配置运行用户DATABASE_URL、DATABASE_CA（如需）、APP_ORIGIN。生产不设置DATABASE_MODE=pglite，任何秘密不得使用NEXT_PUBLIC_前缀。
8. DATABASE_URL中的用户名与密码需URL编码；生产连接串不要加sslmode等SSL参数，统一通过驱动验证配置。DATABASE_URL不可由浏览器填写或获取。
9. 配置完成后部署账号版本，实测登录API、创建学生／教师、强制改密、停用和旧会话失效。无数据库时保留503而不是演示放行。
10. 验证最小权限、备份恢复、20人并发和预算告警后，才允许邀请老师使用真实账号。第一阶段依然只用合成／授权模拟素材。

## 5. 环境变量表

| 名称 | 本地 | 线上 | 说明 |
|---|---|---|---|
| DATABASE_MODE | pglite | 不设置 | 只控制本地嵌入式数据库 |
| PGLITE_PATH | .local/database | 不设置 | 本地磁盘目录 |
| DATABASE_URL | 可不设置 | 必填秘密 | 标准PostgreSQL连接串 |
| DATABASE_TLS | 使用本地PG时按需 | 生产强制TLS | 不允许生产禁用证书校验 |
| DATABASE_CA | 通常不需要 | 按云证书要求 | PEM；也接受转义换行 |
| APP_ORIGIN | http://localhost:3002 | https://稳定网站域名 | 用于POST来源校验；无末尾斜线及路径 |
| BOOTSTRAP_USERNAME/PASSWORD | 初始化时使用 | 仅受控初始化终端 | 不应常驻云项目配置 |

EdgeOne如果对单个环境变量有长度限制，CA证书可能不适合直接放变量；需核实平台秘密文件能力或提供可被系统信任的CA链，不能截断证书或取消TLS校验。秘密文件挂载方式未实施，属于部署依赖。

## 6. 运维、备份与回退

- 正式上线前：开启云端自动备份，记录保留期、可恢复点和费用；建议先以每日备份、保留7天评估，实际RPO/RTO由医院确认。
- 每次数据库迁移前建立备份点；在隔离测试库恢复并验证账号数量、授权和审计。恢复后清空sessions，要求重新登录，避免恢复已撤销旧会话。
- 运行用户不得拥有删库／改表权限。备份文件加密并限制访问，不上传GitHub。数据库与对象存储后续需协调恢复版本。
- 发布失败先回退应用版本；本轮建表为增量，不用DROP回退账号数据。回退到旧公开演示版本时应关闭真实账号入口并明确演示边界，不能冒充真实系统继续营业。
- 登录401：检查会话／停用／撤权；403：检查改密要求、角色或APP_ORIGIN；503：由运维检查连接／TLS／建表，日志不输出密码或完整连接串。
- 设置云数据库存储、连接数、函数失败率和AI费用告警。总预算100元是目标，不是平台已设置硬上限。确定告警阈值后再开自动调用AI。
