## 本地使用

需要 Node.js 22或24、pnpm 11.19.0。安装依赖后运行：

```sh
pnpm install --frozen-lockfile
## 先按 .env.example 创建被忽略的 .env.local（本地配置）
pnpm db:migrate
node --env-file=.env.local scripts/database.mjs bootstrap --generate-local
pnpm dev
```

打开本地3002端口登录。首次本地管理员凭据在被忽略的 `.local/首次管理员登录.txt`；如已进行自动浏览器验收，文件记录的是验收改密后的当前密码。建议登录后再次改密，并删除凭据文件。管理员可新建学生／教师，不再任意切换未授权角色。旧科研平台3001端口不受影响。

```sh
pnpm test
pnpm build
pnpm start
```

`pnpm start`是生产模式，必须配置独立PostgreSQL，不支持本地PGlite；只体验本机账号请使用`pnpm dev`。

图片使用原始PNG且关闭Next图片优化，sharp构建脚本显式保持禁用。账号测试使用真实本地PG引擎，覆盖认证、机构／角色隔离及会话撤销。生产构建包含动态账号API，但不代替云数据库、真实上传、录音、评分和并发验收。
