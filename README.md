# 病理教学平台 · 独立迁移项目

这是病理教学网站的独立开发仓库，复用既有教学页面与蓝紫色 Design System，不依赖原科研平台运行。

## 当前状态

**当前为迁移预览，不是已完成的可用MVP，不能用于真实考试或患者数据。**

- 已迁移：标准／院方病例库页面、考试中心、作答与示例解析、考试记录、错题集、学生五维页面；教师记录、三类分析及四维画像页面。
- 教师录音、转写、问答与同步回放仅为演示UI，明确标注，不访问麦克风，不增加人工录入流程。
- 学生页面继承原型示例题目和本机演示保存，尚无服务端账号、RBAC、考试计时、持久化上传或DeepSeek调用。目录中的三种卷型标签尚不代表已实现三套真实试卷结构。
- 三个示例病例暂共用合成图片与演示题库；仅用于界面验证，不是对应病种医学金标准。真实多图题库与卷型数据将在后端阶段替换。
- 普通图片使用相对缩放比例；WSI第二期接入。

## 本地使用

需要 Node.js 22或24、pnpm 11.19.0。安装依赖后运行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开本地3002端口页面。顶部可切换学生／教师演示视角，这不是账号登录。旧科研平台3001端口不受影响。

```sh
pnpm test
pnpm build
pnpm start
```

图片使用原始PNG且关闭Next图片优化，sharp构建脚本显式保持禁用。当前迁移测试覆盖导航输入和隔离边界；构建验证编译与页面生成，不代替真实上传、录音、评分及权限验收。
